# うちゅうのおさんぽ — 実装仕様書

作成日: 2026-11-04  
プロジェクト: child_games / 対象: PCで遊ぶ4歳児  
URL案: `/games/space-walk` / 状態: 実装前の仕様案。速度・距離・時間は試遊で調整する。

## 1. このゲームで届けたい体験

矢印キーで宇宙船を動かすと、窓の外の星が流れる。気になる惑星へ近づき、挨拶すると、閉じていた花が開いたり雲から生き物が出てきたりする。「行ってみたら何かがいた」という探索を楽しむ。

追いかけられたり、落ちたり、燃料切れになったりしない宇宙。移動する自由と、立ち寄った場所の反応を主役にする。帰ってきたら、出会ったものが並んだ旅の絵日記を見せる。

## 2. 初回リリースの範囲

- 宇宙船1種類、架空の惑星3つ、任意で集める流れ星6個。
- 上下左右の自由移動と、惑星までの自動飛行を併用する。
- 各惑星に「挨拶」と「もう一度遊ぶ」の2段階の反応。
- いつでも帰還でき、訪問数にかかわらず絵日記を作れる。
- 1回3〜5分程度。訪問順は自由。3つすべてを訪ねるのは任意の目標。

戦闘、体力、燃料、重力シミュレーション、実在の天体を教える機能は初回に含めない。空想の宇宙であることが分かる名前と絵にする。

## 3. 画面・アート

| 画面 | 内容 |
| --- | --- |
| 出発 | 宇宙船と大きな再生ボタン。「どこへいこう？」 |
| 探索 | 中央の宇宙、下に矢印とSpace、上に3惑星の絵と帰還ボタン |
| 惑星との交流 | 近づいた惑星を見やすくし、吹き出しと挨拶ボタンを表示 |
| 絵日記 | 訪れた惑星・出会った生き物・星を、絵で順番に並べる |

濃い青紫を背景に、桃色・黄色・ミントの惑星。星を明滅させ続けず、少数のゆっくりしたきらめきにする。船の進行方向は噴射と向きで分かるようにし、背景スクロールは穏やかにする。

## 4. 世界と出会い

| 惑星 | 遠くから見える手がかり | 初めての挨拶 | もう一度遊ぶ |
| --- | --- | --- | --- |
| はなのほし | 大きなつぼみ | 花が開いて丸い生き物が手を振る | 花びらが傘になり、花粉の星が舞う |
| くものほし | 帽子のような雲 | 雲が持ち上がってふわふわの子が出る | 雲を形替えして、魚やウサギになる |
| おとのほし | 音符形の岩 | 岩が3つの音を鳴らして挨拶 | 宇宙船に合わせ、短いメロディーを返す |

惑星ごとに移動先の絵・鳴る音・反応を変える。単に色違いのキャラクターにしない。生き物は船を追いかけず、その場所で遊ぶ。

## 5. 進行と操作

| 状態 | 入力・条件 | 反応・次の状態 |
| --- | --- | --- |
| `ready` | 再生 | 船がゆっくり出発し`exploring`へ |
| `exploring` | 矢印／画面の方向ボタン | 船が移動。惑星へ近づくと挨拶の案内 |
| `exploring` | 1〜3／惑星カード | 指定惑星への自動飛行。到着で停止し案内を表示 |
| `exploring` | Space／挨拶 | 近くに惑星があれば`encounter`。遠ければ進行方向のヒント |
| `encounter` | 約4秒の演出 | 初回なら出会いを記録し、`exploring`へ |
| `exploring` | Enter／かえる | 約3秒の帰還後、`journal`へ |
| `journal` | またいく | 同じ旅の発見を保って探索再開。新しい旅ではリセット |

矢印は押している間だけ移動し、離すと短く減速して止まる。1〜3はキーボード上段の絵と惑星の顔を対応させる。クリックだけでも惑星カードと挨拶・帰還を使って一巡できる。細かい操縦を必須にしない。

## 6. 移動・発見のルール

- 世界の初期案は2400×1000論理座標、表示窓は約960×540。移動速度は毎秒220〜260座標を目安とする。
- 斜め移動は速度を正規化する。世界の端で穏やかに止まり、画面外へ消えない。惑星に当たっても損傷しない。
- カメラは船を追うが、交流中は惑星と船が同時に見える構図で固定する。
- 交流の範囲は見た目より広めにし、目印の輪に少し入れば挨拶できる。精密な着陸は要求しない。
- 自動飛行は惑星の近くで止まる。矢印を押すと自動飛行を即座に解除し、子供の入力を優先する。
- 惑星が遠い時のSpaceは、近い未訪問惑星への絵の矢印を出す。失敗音は鳴らさない。全訪問後は最寄りを示す。
- 流れ星は近くを通ると自動で集まる。取り逃しても残り、全収集を帰還の条件にしない。
- 絵日記には訪問順の小さな絵と出会いの動きを置く。0訪問でも宇宙船と「おさんぽしたね」で完成させる。
- 3惑星訪問時は一度だけ、3体が遠くから手を振る通信が届く。操作を止めず、帰還を強制しない。

## 7. 必要な素材

| 分類 | 素材 |
| --- | --- |
| 船 | 宇宙船、噴射、窓の顔、向きの差分。船体を過剰に回転させない |
| 宇宙 | 背景2層、静止星、流れ星、出発地点 |
| 惑星 | 3惑星の待機と変化、各生き物、花・雲・音符の部品 |
| UI | 惑星カード、方向ボタン、挨拶、帰還、訪問印、絵日記の枠 |
| 演出 | 発見の輪、収集の軌跡、帰還の航跡、通信の顔 |
| 音 | 控えめな噴射、星の収集、3種の挨拶と反応、帰還、案内、BGM |

透過WebP/PNG、UIはSVG。噴射音は連続しても疲れない音量にし、星が重なっても収集音の同時数を制限する。音なしでも惑星の変化を理解できる。

## 8. 技術構成とデータ

React + TypeScript + Vite。世界はDOM画像を論理座標で置き、カメラのtransformで表示範囲を動かす。移動は`requestAnimationFrame`と時間差で処理し、Reactの再描画頻度に速度を依存させない。

- `SpaceState`: phase、shipPosition、cameraPosition、visitedPlanetIds、collectedStarIds、visitOrder、autopilotTargetId、encounterId。
- `PlanetDefinition`: id、position、interactionRadius、assets、firstEncounter、repeatEncounter。
- 連続移動の座標と論理イベントを分離し、近接判定は論理座標で行う。
- タブ復帰の大きな時間差をそのまま適用せず、更新時間に上限を設ける。
- 自動飛行は単純な直線到着で十分。道をふさぐ障害物を置かない。

配置案: `src/games/space-walk/{SpaceWalkGame.tsx,reducer.ts,world.ts,useFlight.ts,components/,styles.css}`。素材は`public/assets/space-walk/`。旅の記録はセッション中だけ保持する。

## 9. 共通UI・中断・読み込み

主要ボタンは64px以上を目安にし、1366×768でも操作部が宇宙を覆いすぎない。矢印によるページスクロールはゲームが入力を扱う時だけ抑止する。設定操作のキーは奪わない。

設定・タブ移動・フォーカス喪失で移動、交流、音を一時停止し、全方向の押下状態を解除。復帰後は再開を待つ。ページ離脱時にフレームループと音を破棄する。素材の先読み失敗時は再試行を出す。動きを抑える設定では背景の視差と大きなカメラ演出を弱める。

## 10. 受け入れ条件

1. 上下左右・斜めで速度が極端に変わらず、船が世界の外へ出ない。
2. 3惑星すべてに自由移動と自動飛行の両方で到着できる。
3. 自動飛行中の矢印入力が優先される。
4. 広い交流範囲で挨拶でき、遠い場合はヒントになる。
5. 初訪問だけ記録され、再訪で絵日記が重複しない。
6. 0訪問、1訪問、全訪問のどの状態でも帰還して完成できる。
7. 星をすべて集めなくても遊びが止まらない。
8. キーボードだけ／クリックだけで旅と帰還を完了できる。
9. 中断・復帰後に船が飛び出したり音が残ったりしない。
10. 画面サイズ・音なし・Chrome／Safari／Edgeの確認状況を記録する。

移動速度・境界・訪問の重複防止をユニットテストし、操縦感とカメラはブラウザで確認する。試遊では「自分から気になる場所へ向かうか」「止まりたい所で止まれるか」を観察する。

## 11. 実装順序と公開

1. 仮の船と3つの丸で、移動・カメラ・境界を確認する。
2. 自動飛行と広い交流範囲を実装し、クリックだけでも移動できるようにする。
3. 3つの異なる出会い、訪問記録、自由帰還をつなぐ。
4. 流れ星、旅の絵日記、全訪問の通信を加える。
5. 本番画像・音、中断と再訪、表示倍率を確認する。
6. 試遊で移動速度と距離を調整し、ホームに登録する。

GitHub + Cloudflare Pagesを候補とし、`npm run build`の`dist`を配信。プレビュー後mainへ反映し、直接URLも確認する。本書作成では実装・公開を行わない。

## 12. 将来の拡張と守ること

船の色替え、新しい星、絵日記保存、親子向けの実在天体モードを候補にする。自由移動が難しい子も同じ出会いを楽しめるよう、自動飛行を補助ではなく正式な遊び方として残す。

## 13. 初回30秒の演出と試遊での判断

出発地点から4秒ほど飛ぶと届く位置に、はなのほしを置く。最初から右側につぼみが少し見え、右矢印の絵を1回だけ動かす。移動できた時点で説明を止め、噴射・背景の流れ・船の位置の変化を見せる。別の方向へ行っても止めない。

惑星の近くでは、船と花の間に挨拶の波を表示する。Spaceを押すと花が開き、出てきた生き物が船の動きと同じ方向に手を振る。最初の30秒で1回の出会いを作りつつ、移動が難しければ惑星カードの自動飛行を絵で示す。

試遊で行き過ぎる場合は交流範囲を広げ、制動を強める。自動飛行ばかり使っていても自由操縦を強要しない。2回目はまだ会っていない生き物や再訪時の変化を見たくなることを狙い、広さだけを増やさない。
