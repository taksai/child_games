# きょうりゅう発掘隊 — 実装仕様書

作成日: 2026-11-04  
プロジェクト: child_games / 対象: PCで遊ぶ4歳児  
URL案: `/games/dinosaur-dig` / 状態: 実装前の仕様案。難度・時間は試遊で調整する。

## 1. このゲームで届けたい体験

土の中から白いものが少し見える。掘ると長い骨、ブラシをかけると大きな頭。「これは誰だろう？」と予想しながら、見つけた骨をつなぎ、最後に恐竜の姿が現れる。

主役は当てものの正解数ではなく、少しずつ正体が分かる発見。最後の恐竜は子供が組み立てた骨格に肉付きのイラストが重なる演出で登場し、特技を見せて挨拶する。実際に化石が生き返るという説明はしない。

## 2. 初回リリースの範囲

- 3つの発掘場所、恐竜はトリケラトプス・ステゴサウルス・首の長い恐竜の3種。
- 1体を頭・胴・尾・脚など6つの「骨のまとまり」で表現する。実際の骨の本数とは区別する。
- 掘る→ブラシで掃除→6パーツを組み立てる→姿と動きを見る。
- 1回3〜5分程度。発掘回数、時間制限、失敗終了は設けない。
- 発掘の順番は変わるが、必要なパーツは必ず全部手に入る。

リアルな地層学習、恐竜名の読み書き、持ち物管理、自由な骨の合成は初回に含めない。

## 3. 画面とアート

| 場面 | 内容 |
| --- | --- |
| 地図 | 森・赤土・川辺の3つの場所。恐竜の全身はまだ見せない |
| 発掘 | 地面に6つの大きな作業場所。見つけた骨は下のトレーに並ぶ |
| 掃除 | 見つけた骨を中央に拡大。ブラシの動きで土が薄くなる |
| 組み立て | 大きな骨格シルエットと、今回つけるパーツ・3つまでの候補位置 |
| おひろめ | 骨格から恐竜の姿へ切り替わり、短い特技を見せる |

探検図鑑のようなオレンジ・緑・空色。骨は丸く、土煙は柔らかくする。怖い牙、追跡、突然の大音量は使わない。形の特徴は残しつつ、骨格の接続や姿は制作時に資料で確認し、名前と図が食い違わないようにする。

## 4. 進行と状態

| 状態 | 入力・条件 | 反応と次の状態 |
| --- | --- | --- |
| `map` | 1〜3／場所をクリック | 発掘場所を決定し`dig`へ |
| `dig` | ←→で場所、Spaceで掘る | 1回ごとに土が割れ、3回で骨が露出。`brush`へ |
| `brush` | Spaceを押す・長押し | ブラシが動き約2秒で土が取れる。トレーへ収納 |
| `collected` | 約1秒の短い演出 | 未発掘があれば`dig`、6個なら`assemble`へ |
| `assemble` | 1〜3／候補位置をクリック | 合えば大きく吸着。次のパーツへ。全6個で`reveal` |
| `reveal` | 約5秒 | 姿が重なり、恐竜が挨拶。`complete`へ |
| `complete` | Space／特技ボタン | 首を伸ばす・葉を食べるなどを再生。別の場所／ホームも選べる |

発掘は作業場所を自由に選べる。発掘済みの場所には旗を立て、再選択しても失敗せず旗が揺れる。骨を見つけた瞬間は操作を短く止めて見せ、次の入力が掃除や組み立てまで通り抜けないようにする。

## 5. 操作と案内

| 操作 | キー・画面 |
| --- | --- |
| 地図から選ぶ | 1〜3／場所の絵 |
| 掘る場所を移す | ←→／地面をクリック。2行3列の見た目でも選択順は一列で循環 |
| 掘る | Space／スコップボタン。1押下1回 |
| ブラシをかける | Space／ブラシボタン。長押し可 |
| 組み立て | 画面に示す1〜3／大きな候補位置 |
| 特技を見る | Space／足跡ボタン |

「ほってみよう」「やさしく はらおう」「どこにつくかな？」を短い音声と絵で案内する。組み立ての候補番号はキーとの対応表示であり、数字を読むことを問題にしない。

## 6. 発見・組み立て・ごほうびの設計

- 初回の1パーツは特徴的な尾か角を含む物にし、すぐ予想が生まれるようにする。残りの出土順はシャッフルする。
- 掘る3回のうち1回目で白い輪郭、2回目で形の半分、3回目で全体が見える。毎回同じ土煙だけでは済ませない。
- 掃除中は土が実際に減り、表面の溝が現れる。早く連打する必要はない。
- 組み立ては一度に1パーツ。空いている位置から正解と最大2つの別候補を大きく表示する。終盤は候補数を減らす。
- 間違うと骨がトレーへふわっと戻り、「かたちをみてみよう」。2回迷ったら正しい輪郭と同じ形を穏やかに点灯する。
- 接続済みの骨を外す必要はなく、誤答で進捗を戻さない。正解位置を毎回同じ番号に固定しない。
- トリケラトプスは花を角に載せる、ステゴサウルスは背中に小鳥を乗せる、首の長い恐竜は高い葉を食べる。姿だけでなく動きの違いを作る。
- 完成後の説明は「つのがあるね」「くびがながいね」など、見える特徴を1つだけ。未確認の生態を断言しない。

## 7. 必要な素材

| 分類 | 内容 |
| --- | --- |
| 地図・背景 | 3つの場所カード、発掘地3背景、組み立て台 |
| 骨格 | 3種×6パーツ、全体シルエット、土付きマスク、各接続座標 |

| 道具・演出 | スコップ、ブラシ、旗、トレー、土煙、きらめき、小鳥・花・葉 |
| UI | 場所選択、キー表示、候補枠、図形付きの収集印、再プレイ |
| 音 | 掘る3段階、ブラシ、発見、吸着、完成、控えめな恐竜の声、案内、BGM |

透過WebP/PNGで恐竜と骨を分け、輪郭ガイドはSVG。原画から骨格パーツを独立させても接続が自然に見えるよう、共通の座標系で制作する。お披露目に怖い咆哮を使わない。

## 8. 実装構成とデータ

React + TypeScript + Vite、DOMレイヤーとCSSアニメーションで実装する。骨格をつなぐための物理演算は不要。

- `DigState`: phase、siteId、selectedSpot、spotDepths、collectedPartIds、cleanProgress、assemblyIndex、attachedPartIds、missCount。
- `DinosaurDefinition`: id、parts、slotCoordinates、silhouette、revealImage、featureVoice、trick。
- パーツごとの正しい接続先をIDで照合。画像の重なり率では判定しない。
- 出土配置は開始時に一度決定し、再描画で変わらない。全6パーツの重複・欠落を禁止する。
- 掃除の長押しは経過時間で処理し、掘る単発入力とは区別する。
- 完成済み配列と出土済み配列を分け、掃除前に組み立てへ進まないようにする。

配置案: `src/games/dinosaur-dig/{DinosaurDigGame.tsx,reducer.ts,definitions.ts,components/,styles.css}`。素材は`public/assets/dinosaur-dig/`。音設定以外の永続保存は初回に設けない。

## 9. 子供向けUIと中断

クリック対象は64px以上を目安とし、骨格の細い線そのものを押させず大きな候補枠を使う。1366×768でもトレーと作業場所を同時に見せる。キーの位置は画面のキーボード図で示す。

設定表示・タブ移動・フォーカス喪失で掃除、演出、音を止め、押下状態を解除する。再開ボタンで復帰。ルートを離れたら音とイベントを破棄する。素材先読みの失敗時は再試行を案内する。ミュート中も掘った段階・発見・正解が絵で分かる。

## 10. 受け入れ条件

1. 3場所すべてで6パーツが重複なく集まり、必ず完成できる。
2. 発掘の順番を変えても骨格と姿が一致する。
3. 掘るたびに露出が進み、掃除で土が減ることが見える。
4. 発掘済み場所への入力でパーツが重複しない。
5. どの組み立て問題にも正解候補が必ず含まれる。
6. 間違えても進捗が戻らず、連続誤答時に形のヒントが出る。
7. 全工程をキーボードだけ／クリックだけで操作できる。
8. 一時停止と復帰で掃除や演出が飛ばない。
9. 別の場所で再プレイすると前の骨・ヒント・音が残らない。
10. 音なし、画面倍率変更、Chrome・Safari・Edgeの確認結果を記録する。

出土配置・候補生成・状態遷移をユニットテストし、骨の位置合わせはブラウザで確認する。試遊では、完成前に正体を予想するか、骨の形を自分から見比べるかを観察する。

## 11. 実装順序と公開

1. 1種6パーツの位置合わせを先に作り、完成像の気持ちよさを確認する。
2. 掘る3段階、掃除、収集トレーをつなぐ。
3. 候補選択とヒントを実装し、間違っても進めることを確かめる。
4. 姿のお披露目と特技、残り2種を追加する。
5. 本番画像・音・案内を入れ、中断と再プレイを確認する。
6. 試遊でパーツの細かさと待ち時間を調整し、ホームに登録する。

既存方針のGitHub + Cloudflare Pagesを候補とし、`npm run build`の`dist`を配信する。プレビュー確認後mainへ反映し、直接URLも確認する。本書作成では実装・公開を行わない。

## 12. 将来の拡張と守ること

新しい恐竜、図鑑、親子で読める説明、出土物の展示室を追加候補にする。最初から骨格を細分化せず、「少し見える→予想する→分かる」という発見の間を守る。

## 13. 初回30秒の演出と試遊での判断

地図から入ると、最初に選択する場所には特徴的なパーツを置く。ただし別の場所を掘る自由は残す。スコップの1打目で土の下に白い線、2打目で角や尾の特徴、3打目で全体を見せる。子供が「これ何？」と予想する余地を作り、発見前に恐竜名を読み上げない。

ブラシの場面では、スコップからブラシへ道具の絵を大きく入れ替える。Spaceを離して押し直すと土がすっと減り、形の細部が現れる。最初の30秒で、最低1パーツを自分で見つけてきれいにできるテンポを目指す。

試遊で白い線が見えても気付かない場合は、掘る回数を増やすより土との明度差と露出面積を調整する。組み立てで候補を総当たりする場合は、問題を難しくする前に形を並べて見せる。2回目は別の場所で「今度は違う骨が出る」という予想を楽しめるようにする。
