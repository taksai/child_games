# ころころボールこうじょう — 実装仕様書

作成日: 2026-11-04  
プロジェクト: child_games / 対象: PCで遊ぶ4歳児  
URL案: `/games/ball-factory` / 状態: 実装前の仕様案。軌道・速度・演出時間は試遊で調整する。

## 1. このゲームで届けたい体験

坂をトランポリンに替えたら、ボールが高く跳ねて鐘が鳴った。トンネルに替えたら、少し隠れて反対側から模様付きで出てきた。「ここだけ変えたらどうなる？」を何度も試せる、小さなからくり装置を作る。

難しい物理パズルを解くのではなく、自分で選んだ仕掛けの結果を見る遊び。どの組み合わせでもボールは最後まで進み、通った仕掛けで最後の作品が変わる。調整して再実験することを一番の楽しさにする。

## 2. 初回リリースの範囲

- 3つの大きな設置場所、坂・トンネル・トランポリンの3種類。
- ボール3色、1回に流すボールは1個。
- 最初から坂3つの動くコースを用意し、部分的に交換できる。
- 仕掛けに対応する絵の具・模様・鐘と、最後にできる「ころころアート」。
- 27通りの仕掛けの組み合わせをすべて完走可能にする。
- 1回2〜5分程度、1試走は約8〜12秒。

自由配置、パーツの角度調整、重力値、ボールの大量投入、失敗して落ちる穴は初回に含めない。

## 3. 画面とアート

| 場面 | 内容 |
| --- | --- |
| 制作 | 左の投入口、中央の3つの設置枠、右の完成出口。下に仕掛けの絵 |
| 試走 | 選んだ仕掛けをボールが通り、各場所で異なる動きと音 |
| 結果 | 出口に小さな絵が完成。変更した場所を指す案内と、もう一度の導線 |
| おひろめ | 仕掛けと完成アートを並べた工場ポスター。「つづきをつくる」「ホーム」 |

黄色・水色・朱色の積み木工場。装置の支点・入口・出口を大きく見せる。背景の歯車は少なくし、ボールと連動する歯車だけを目立たせる。ボールには目または大きな模様を付け、追いかけやすくする。

## 4. 3種類の仕掛けの違い

| 仕掛け | 見た目と軌道 | 通ると起きること | アートに残るもの |
| --- | --- | --- | --- |
| 坂 | 低い曲線をころころ転がる | 下の絵の具ローラーを回す | ボール色の太い線 |
| トンネル | 暗くせず少し中が透ける。途中で一瞬隠れる | 中でスタンプが押され、同じ模様が出口に出る | 星・丸・波のスタンプ |
| トランポリン | 布が沈んで大きく跳ねる | 上の鐘を鳴らし、紙吹雪が落ちる | 色の紙吹雪のまとまり |

3つの設置場所でトンネルの模様と鐘の高さ・音を変える。仕掛けの種類ごとの基本挙動は同じにし、場所による違いは小さな発見にする。各部品の入口・出口は同一の基準位置につなぐ。

## 5. 進行と操作

| 状態 | 入力・条件 | 反応と次の状態 |
| --- | --- | --- |
| `ready` | 再生 | 既定の坂3つを見せ`building`へ |
| `building` | ←／→ | 注目する設置場所を移す |
| `building` | 1坂・2トンネル・3トランポリン | 選択場所の仕掛けを交換。短い動きで特徴を示す |
| `building` | 4／ボール色 | 3色を循環 |
| `building` | Space／ころがす | コースと色を固定して`running`へ |
| `running` | 約8〜12秒 | 全仕掛けを通り、アートを生成して`result`へ |
| `result` | Space／かえる | 同じコースを保って`building`へ |
| `result` | Enter／できあがり | `complete`で工場ポスターを表示 |
| `complete` | 続きを作る | コースを保って`building`へ |

クリックは設置枠を選び、仕掛けカードを押す2段階。Space・番号キーの長押しは無視し、試走中はコースを編集しない。結果から戻ったら最後に変えた場所を選択したままにし、1か所だけ変えて再試走しやすくする。

## 6. 試して変える面白さ

- 交換した場所の周りだけを弾ませる。コース全体を作り直す演出にせず、どこが変わったか見せる。
- 最初の試走後、「ここをかえると？」と未変更の枠を一度だけ穏やかに案内する。変更を必須にしない。
- 坂は転がる音、トンネルは短いこもった音、トランポリンは布と鐘の音。動きと音の違いをそろえる。
- ボールの回転は移動距離に合わせ、止まっている時は回らない。跳ねる瞬間には布が沈んでから戻る。
- トンネルで隠れる時間は0.8秒以内を目安とし、小窓に影を見せる。見失った不安を長引かせない。
- アートは1→2→3の順に線・模様・紙吹雪を重ねる。同じコースと色で試すと同じ作品になる。
- 直前の作品は結果画面に小さく1枚だけ残し、今回と見比べられる。違いの点数や優劣は付けない。
- 「ひとつもどす」で部品交換とボール色を操作単位で戻す。最大30操作。試走そのものは編集履歴に含めない。
- 同じ構成をもう一度走らせてもよい。結果を毎回ランダムにせず、予想と結果の関係を保つ。

透過WebP/PNGとSVGを使う。アートは正確な順序で重ねられるSVGパーツとして用意し、画像生成は原画作成にだけ使う。線や接続点を画像生成任せにしない。

## 8. 技術構成とデータ

React + TypeScript + Vite。初期版は自由な剛体物理ではなく、部品ごとに設計した軌道と通過イベントをつなぐ方式にする。部品を替えた結果が一貫し、全組み合わせで完走できることを優先する。

- `FactoryState`: phase、modules[3]、selectedSlot、ballColorId、history、runSnapshot、currentArtwork、previousArtwork。
- `ModuleDefinition`: kind、entry、exit、path、duration、occlusionRange、triggerEvents。
- 3枠それぞれのローカル座標に軌道を定義し、入口・出口の座標を一致させる。
- 坂は下側の曲線、トランポリンは圧縮→上側の放物線、トンネルは部分的な非表示を使う。
- 軌道は経過時間を弧長に近い進み方へ変換し、不自然な速度の急変を抑える。部品境界で位置が跳ばないようにする。
- 鐘・ローラー・スタンプは通過時刻に1回だけ発火し、アート生成は記録したイベントから決定的に作る。
- 1試走1ボール。終了・中断・ルート離脱時に全予約を停止する。

配置案: `src/games/ball-factory/{BallFactoryGame.tsx,reducer.ts,modules.ts,runner.ts,artwork.ts,components/,styles.css}`。素材は`public/assets/ball-factory/`。作品は今回と前回の2つだけセッション中に保持する。

## 9. 子供向けUI・中断

1366×768で全コースが見え、追いかけるためのスクロールを不要にする。仕掛けと選択枠は64px以上を目安にし、選択中の場所に輪郭と小さな旗を付ける。矢印はゲーム操作中だけページスクロールを抑止する。

設定・タブ移動・フォーカス喪失でボール、仕掛け、音を停止し、再開を待つ。再開時に通過イベントを二重発火させない。動きを抑える設定ではカメラの揺れと紙吹雪を弱めるが、軌道は理解できるように残す。素材先読みの失敗は再試行する。

## 10. 受け入れ条件

1. 3枠×3種類の全27構成でボールが最後まで進む。
2. 部品の境界でボールの位置が飛ばず、入口・出口がそろう。
3. 坂・トンネル・トランポリンの動きと音を見分けられる。
4. 鐘・スタンプ・ローラーが実際に通過した時に1回だけ反応する。
5. 同じコースと色から同じアートができ、変更した要素が作品へ反映される。
6. 前回の作品が1枚だけ保持され、比較できる。
7. 1か所だけ変更して繰り返し試せ、取り消しも正しく動く。
8. キーボードだけ／クリックだけで配置、試走、完成まで進める。
9. 試走中の連打・中断・再開でボールや音が増えない。
10. 音なし、画面倍率、Chrome・Safari・Edgeの確認状況を記録する。

全構成の接続、イベント一意性、アートの決定性をユニットテスト。軌道、見失わない速度、絵と接続点の一致はブラウザで確認する。試遊では「変えた場所の結果を待つか」「もう一度の前に予想を話すか」を観察する。

## 11. 実装順序と公開

1. 仮の線と丸で3枠の軌道と接続点を作り、全27構成を確認する。
2. 部品交換、選択枠、ボール色、取り消しを実装する。
3. 通過イベントと絵の具・スタンプ・鐘を接続する。
4. 結果のアート、前回比較、完成ポスターを作る。
5. 本番素材と音、跳ねる布とボールの回転を仕上げる。
6. 中断・連打・再訪を確認し、試遊で速度を調整してホームに登録する。

GitHub + Cloudflare Pagesを候補とし、`npm run build`の`dist`を配信。プレビュー後mainへ反映し、直接URLも確認する。本書作成では実装・公開を行わない。

## 12. 将来の拡張と守ること

シーソー、風車、分かれ道、部品枠の追加、作品保存を候補とする。自由度を増やす前に「1か所変えると、その違いを目で追える」ことを守る。初期版から正確な角度や複雑な接続を要求しない。

## 13. 初回30秒の演出と試遊での判断

最初のカーソルは真ん中の枠に置き、3つとも坂の状態を見せる。まずSpaceでそのまま走らせられるようにし、先に変更した子も妨げない。最初のボールがローラーを回し、線の作品を作る所までを約10秒で見せる。

結果から戻ったら、真ん中の枠とトランポリンの絵を一度だけ弾ませる。3を押してからSpaceで再試走すると、同じ場所でボールが高く跳ね、前は鳴らなかった鐘が鳴る。前回の線だけの作品と、紙吹雪が加わった作品を並べる。最初の30秒で1か所の変更と結果の違いを経験できる流れを目指す。

試遊でボールを見失う場合は背景を減らし、速度と隠れる時間を直す。違いに気付かない場合は、選択肢を増やすより跳躍の高さ・鐘の動き・作品の差を広げる。2回目は自分から別の枠も変え、走る前に結果を予想したくなることを狙う。
