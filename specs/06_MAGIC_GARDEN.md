# ふしぎなおにわ — 実装仕様書

作成日: 2026-11-04  
プロジェクト: child_games / 対象: PCで遊ぶ4歳児  
URL案: `/games/magic-garden` / 状態: 実装前の仕様案。成長時間・変化は試遊で調整する。

## 1. このゲームで届けたい体験

小さな種に何をあげるかで、育つものが変わる。水をたくさんあげると水玉の花、太陽なら大きな明るい花、魔法なら光る花。「次は違う育て方にしてみよう」が自然に生まれる庭を作る。

世話を忘れても枯れず、どの選択でも成長する。正しい園芸手順を教えるゲームではなく、空想の植物で変化を試す遊び。育った植物は庭に残り、並んだ姿や、触った時の反応まで楽しめる。

## 2. 初回リリースの範囲

- 花・木・きのこの3種類の種、庭に3つの鉢。
- 水・太陽・魔法の3つの世話を、1株につき3回選ぶ。
- 各種4完成形、合計12種類。選択の組み合わせから決定し、同じ育て方は同じ結果になる。
- 種→芽→つぼみ／若木→完成の段階変化と、植物ごとの遊ぶ反応。
- 1株1〜2分、庭全体3〜5分程度。1株できた時点でもお披露目可能。

実時間の待機、翌日のログイン、枯れる処理、現実の栽培指導、図鑑の全収集は初回に含めない。

## 3. 画面と見た目

| 場面 | 内容 |
| --- | --- |
| 庭 | 3つの大きな鉢。空の鉢には土と種の印。完成植物も同時に見える |
| 種選び | 花・木・きのこの種袋。袋には完成形ではなく基本のシルエット |
| お世話 | 選んだ鉢を少し大きくし、下に水・太陽・魔法の道具 |
| 成長 | 約2秒で葉や茎が伸びる。世話の絵が小さな履歴として残る |
| 庭のおひろめ | できた植物に蝶や小鳥が訪れる。庭全体を記念フレームで見せる |

明るい若草色にピンク・黄色・空色。土も鉢も丸く、種は大きめ。水は波紋、太陽は光、魔法は星と、色以外でも世話の種類を区別する。

## 4. 進行と操作

| 状態 | 入力・条件 | 反応と次の状態 |
| --- | --- | --- |
| `garden` | ←→／鉢をクリック | 注目する鉢を切り替える |
| `garden` | Space／選ぶ | 空なら`seedSelect`、完成済みなら`plantPlay` |
| `seedSelect` | 1〜3／種袋 | 種が土に入り`care`へ |
| `care` | 1水・2太陽・3魔法 | 選んだ道具が動き`growing`へ |
| `growing` | 約2秒 | 世話を1回記録。3回未満なら`care`、3回なら`mature` |
| `mature` | Space／遊ぶ | その植物の反応。Enter／庭へで`garden` |
| `garden` | Enter／おひろめ | 1株以上あれば`celebration`へ |
| `celebration` | 約6秒 | 植物に生き物が訪れ、`complete`へ |
| `complete` | まだ育てる | 同じ庭を保持して`garden`へ |

世話の3つのボタンは場面に応じて意味を表示する。長押しによる繰り返しは無視する。成長中の入力を次の世話に持ち越さない。満杯の庭でも植物を触って遊べ、新しい庭ボタンからだけ全体を初期化する。

## 5. 育ち方のルール

3回のお世話で、同じ種類が2回以上あればその種類の完成形、3種類を1回ずつ選べば「にじいろ」の完成形になる。順番は記録するが最終結果は回数で決まり、同じ選び方を再現できる。

| 種 | 水が多い | 太陽が多い | 魔法が多い | 全種類1回ずつ |
| --- | --- | --- | --- | --- |
| 花 | 水玉の花：葉から小さな噴水 | 大きな太陽の花：顔の周りが開く | ランタンの花：柔らかく光る | 虹の花：花びらが順番に揺れる |
| 木 | しゃぼん玉の木：泡の実が浮く | お菓子の木：包みの実が揺れる | 星の木：星の実が音を出す | 虹の木：色の葉が輪になって回る |
| きのこ | しずくきのこ：傘から水滴の音 | かさきのこ：大きな傘が広がる | ひかりきのこ：点灯すると小鳥が来る | 虹きのこ：模様が順番に弾む |

これらは空想の変化として描く。世話の途中でも、水なら葉にしずく、太陽なら茎が伸び、魔法なら先端に星が現れる。最終形だけを突然抽選表示しない。

## 6. 触って遊ぶ・取り消し・ごほうび

- 成熟した植物でSpaceを押すと、完成形ごとの反応を約2秒再生する。短い間隔の連打で音や演出を積み重ねない。
- 庭の3鉢は独立して保持し、違う育て方を並べて比較できる。
- 「ひとつもどす」で、現在育てている株の直前のお世話まで戻れる。成熟直後も3回目を戻して別の世話を試せる。
- 庭に戻って別の鉢を選んだ後は、過去の植物の履歴を掘り返さない。鉢ごとの「育て直す」から種選びへ戻し、他の鉢は残す。
- 育て直す操作は絵付きの確認を挟み、空の鉢を選ぶ操作と離して置く。
- お披露目では花に蝶、木に小鳥、きのこに小さなカタツムリが訪れる。鉢の数や種類に関係なく歓迎する。
- お世話がないまま待っていても植物は変化しない。急かすカウントダウンは出さず、道具が穏やかに揺れて案内する。

## 8. 技術構成とデータ

React + TypeScript + Vite、DOM画像の段階差し替えとCSSアニメーション。成長はゲーム内の短い経過時間で処理し、端末時刻やサーバー時刻に依存させない。

- `GardenState`: phase、selectedPotIndex、pots、currentGrowth、paused。
- `PlantState`: seedId、careHistory、growthStage、variantId、undoSnapshots。
- `PlantDefinition`: seedId、stageAssets、variants、reaction、visitorId。
- `resolveVariant(careHistory)`は純粋関数とし、2回以上の世話／全種1回の分岐を網羅する。
- 戻す時は現在の株の状態をスナップショットで戻し、発火待ちの成長演出も取り消す。
- 完成庭の演出は植物のデータから生成し、存在しない鉢に生き物を置かない。

配置案: `src/games/magic-garden/{MagicGardenGame.tsx,reducer.ts,plants.ts,resolveVariant.ts,components/,styles.css}`。素材は`public/assets/magic-garden/`。庭はセッション中のみ保持し、音設定だけを端末内保存する。

## 9. 子供向けUI・一時停止

主要ボタンは64px以上、1366×768で3鉢と道具を同時に見せる。数字だけでなく道具の絵とキーボード上段の位置を示す。すべてクリックでも操作でき、ボタンはTabでもたどれる。

設定・タブ移動・フォーカス喪失で成長、訪問、音を停止し、再開ボタンで復帰する。ページを離れたら予約演出と音を破棄する。素材の先読み失敗時は再試行。音なしでも選んだ世話・成長段階・完成形が分かる。

## 10. 受け入れ条件

1. 3種×全27通りの世話の並びが、定義どおりの12完成形へ到達する。
2. 同じ回数の世話なら順番が違っても最終形が一致する。
3. 毎回の世話の種類が中間段階にも見た目で反映される。
4. 取り消して違う世話を選ぶと、結果も正しく変わる。
5. 3鉢が独立し、1鉢を育て直しても他の植物を失わない。
6. 1株だけでも完成でき、満杯の庭も触って遊べる。
7. キーボードだけ／クリックだけで種選びからお披露目まで進める。
8. 成長中の連打で世話が勝手に複数回入らない。
9. 中断・再開・新しい庭で演出と植物の状態が一致する。
10. 音なし、倍率変更、Chrome・Safari・Edgeの確認状況を記録する。

分岐関数、鉢の独立性、取り消しをユニットテスト。成長のつながりと完成形の区別をブラウザで確認する。試遊では「次は別の世話を試すか」「同じ育て方をもう一度できるか」を見る。

## 11. 実装順序と公開

1. 花1種・4完成形で、3回のお世話と分岐を作る。
2. 中間段階の変化、取り消し、反応を実装する。
3. 3鉢の庭と、1鉢だけでも完成するお披露目をつなぐ。
4. 木・きのこ、訪問する生き物を追加する。
5. 本番画像・音、中断・育て直し・新しい庭を確認する。
6. 試遊で成長速度と案内を調整し、ホームに登録する。

GitHub + Cloudflare Pagesを候補とし、`npm run build`の`dist`を配信。プレビュー確認後mainへ反映し、直接URLも確認する。本書作成では実装・公開を行わない。

## 12. 将来の拡張と守ること

新しい種、夜の庭、庭の画像保存、親子で見返す図鑑を候補とする。「戻ってこないと枯れる」仕組みは入れず、好きな時に試せる庭にする。選び方と結果の関係はランダムで曖昧にしない。

## 13. 初回30秒の演出と試遊での判断

最初は左の空の鉢を選択し、土の上で種袋の絵が跳ねる。種を選ぶと土がふくらみ、小さな芽が顔を出す。道具3つを一緒に見せ、「どれをあげよう？」だけを伝える。最初に水を選ぶことは強制しない。

世話を選んだ直後に、水なら葉がふるえ、太陽なら芽が背伸びし、魔法なら先に星が付く。2秒の成長を終えたら、その世話の絵が鉢の下に残る。最初の30秒で1株目が育ち始め、「選んだ物が植物に残る」と分かることを目指す。

試遊で完成した瞬間を見逃す場合は光を強くするより、成長前に短い間を置き、大きさと形の差を広げる。同じ道具を3回使ってもちゃんと固有の植物になる。2回目は別の鉢へ同じ種を植え、世話だけを変えて比べたくなることを狙う。
