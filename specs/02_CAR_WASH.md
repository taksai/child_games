# どろんこカーウォッシュ — 実装仕様書

作成日: 2026-11-04  
プロジェクト: child_games / 対象: PCで遊ぶ4歳児  
URL案: `/games/car-wash` / 状態: 実装前の仕様案。数値は試遊で調整する。

## 1. このゲームで届けたい体験

泥でよく見えない車を、自分の手でピカピカにする。水を当てると泥が流れ、泡で包むとふわふわになり、ブラシが動くと隠れていた絵が見えてくる。「進むボタンを押した」ではなく、「ここをきれいにした」と感じられる変化を作る。

車はお客さんとして来店する。洗った後は色とステッカーを選んで送り出し、車が自分の得意な動きを見せてお礼をする。消防車なら小さな虹の放水、ショベルカーならバケットでお辞儀する。

面白さの核は、汚れが消える気持ちよさ、泡の大げさな反応、自分が仕上げた車が動くお披露目。

## 2. 初回リリースの範囲

- 消防車、ショベルカー、アイスクリームワゴンの3台から1台選ぶ。
- 水洗い→泡→ブラシ→すすぎ→乾燥→色と飾り→出発の一巡。
- 前・真ん中・後ろの3つの大きな作業範囲。細かいマウス軌跡は不要。
- ボディカラー4色、ステッカー6種類、1台につき飾り3か所。
- 1回2〜4分程度。急がせるタイマー、汚れ残りによる失敗、課金は設けない。

車の自由走行、リアルな流体、部品交換、車体への自由描画は初回には含めない。

## 3. 画面とアート

| 画面 | 内容 |
| --- | --- |
| 選車 | 泥だらけでも形が分かる3台。選ぶとクラクションではなくやさしい挨拶音 |
| 洗車場 | 横向きの大きな車と道具。下に現在の道具の絵とSpaceの案内 |
| 仕上げ | 乾いた車、色の見本、ステッカーの大きな一覧 |
| 出発 | シャッターが開き、車が得意な動きを見せて走り出す |
| 完成 | ピカピカの記念画面。「べつのくるま」「もういっかい」「ホーム」 |

水色とレモン色の洗車場、丸い泡、太い縁取り。泥を不快にせず、チョコレートのような色と形で表現する。車の窓に顔を付ける場合は、汚れを叱る表情ではなく、作業を楽しむ表情にする。

## 4. 進行と状態

| 状態 | 操作・条件 | 反応と遷移 |
| --- | --- | --- |
| `select` | 1〜3／車をクリック | 選んだ車が入庫。`prewash`へ |
| `prewash` | 範囲を選びSpaceを押す・長押し | 水が出て泥が薄くなる。3範囲完了で`foam` |
| `foam` | 同じ操作 | 泡が積もる。3範囲完了で`brush` |
| `brush` | 同じ操作 | 自動ブラシが左右に動き、泥の跡を取る。完了で`rinse` |
| `rinse` | 同じ操作 | 泡が流れて元の車体が現れる。完了で`dry` |
| `dry` | Space／風ボタン | 約3秒の送風で水滴が飛ぶ。`decorate`へ |
| `decorate` | 色とステッカーを選ぶ | 即時に車へ反映。Enterで`departure` |
| `departure` | 約6秒の演出 | 車種固有のお礼、走り出し、`complete`へ |

範囲ごとに約1.5秒の作業で完了する初期案。短く押す操作でも進捗を保持し、長押しでまとめて進められる。完了範囲を繰り返し洗ってもよく、次の範囲への案内だけ出す。工程が変わったら一度キーを離すまで次の道具は動かさない。

## 5. キーボード・クリック操作

| 場面 | キー | 操作 |
| --- | --- | --- |
| 選車 | 1〜3 | 対応する車を選ぶ |
| 洗車 | ←／→ | 前・真ん中・後ろへ作業範囲を移す |
| 洗車 | Space | 現在の道具を使う。長押し可 |
| 仕上げ | 1〜4 | ボディカラーを変更 |
| 仕上げ | ←／→ | ステッカー候補を切り替え |
| 仕上げ | Space | 次の飾り位置へ選択中のステッカーを貼る |
| 仕上げ | Enter | 出発する |

画面の3範囲をクリックして選び、道具ボタンを押しても遊べる。道具ボタンは押している間だけ動く。離す・画面外へ出る・フォーカスを失う場合は停止する。進捗は文字の百分率ではなく、泥・泡・水滴の変化と完了の星で示す。

## 6. 洗う感触と仕上げのルール

- 車体を3つのマスク領域に分け、泥・泡・水滴を別レイヤーで描く。道具の絵と変化する場所を一致させる。
- 泡の工程では大きな泡が一度だけ鼻のような形になり、車がくすぐったそうに揺れる。操作を奪うカットシーンにしない。
- 車ごとに1個、泥の下に小さな模様を隠す。洗うと消防車の星、ショベルの恐竜、ワゴンのアイスが現れる。
- ブラシを使った面は反射が増える。最後のすすぎで明確に「きれいになった」と分かる。
- ボディ色はホイール・窓・消防用具などの識別に必要な部品まで塗らない。
- ステッカーは窓とライトを避けた3つの固定位置に貼る。4回目以降は一番古い位置から上書きし、無制限に重ねない。
- 「ひとつもどす」は色変更・ステッカー貼りを操作単位で戻す。「かざりなおす」は仕上げ前の色と飾りに戻す。
- 飾らず出発しても歓迎する。車種固有のお礼はどの仕上がりにも返す。

## 7. 必要な画像・音

| 分類 | 素材 |
| --- | --- |
| 車体 | 3車種のボディ・窓・車輪・道具の分離画像、色替えマスク、入庫・お礼用差分 |
| 汚れ | 車種別の泥、薄い泥、泡、水滴、反射。3範囲のマスク |
| 道具 | ホース、泡ノズル、大きなブラシ、送風機 |
| 仕上げ | 色見本4色、ステッカー6種、選択枠、取り消しボタン |
| 背景・演出 | 洗車場、シャッター、出発道路、泡、水しぶき、きらめき、虹 |
| 音 | 水、泡、ブラシ、風、貼る音、車種別のお礼、短いBGM、各工程の音声 |

透過WebP/PNGとSVGを使い、車種ごとに描画基準とマスクの座標をそろえる。水などのループ音は工程終了時に止める。現実のサイレンのような強い音をお礼に使わない。

## 8. 実装構成とデータ

React + TypeScript + Vite。車体と汚れはDOM上のレイヤー、マスクとCSS変数で進捗を表現する。リアルタイムの流体やピクセル単位の削り取りは使わない。

- `WashState`: phase、vehicleId、selectedZone、zoneProgress、colorId、stickerSlots、history。
- `VehicleDefinition`: id、画像、洗車領域、色替え領域、飾り座標、お礼アニメーション。
- 各工程の3範囲進捗を独立管理し、次工程開始時だけ初期化する。
- 長押しは押下フラグ＋アクティブ経過時間で計算し、OSのキーリピート回数に依存させない。
- 遷移時の持ち越し入力を防ぎ、工程完了イベントを一度だけ発火させる。

配置案: `src/games/car-wash/{CarWashGame.tsx,reducer.ts,config.ts,useToolHold.ts,components/,styles.css}`。素材は`public/assets/car-wash/`。端末内保存は共通の音設定だけにする。

## 9. 共通UI・中断への対応

主要操作は64px以上を目安とし、1366×768で車と道具を同時に見せる。文字は短いひらがな、道具とキーの絵を併用する。ボタンとグローバルキー処理の二重発火を避ける。

設定表示・タブ移動・フォーカス喪失で長押し、進捗、ループ音を止める。復帰時は再開を待ち、勝手に放水しない。素材は開始前に先読みし、失敗時は再試行を表示する。ミュートでも全工程が理解できる。ページ離脱時に音と入力リスナーを破棄する。

## 10. 受け入れ条件

1. 3車種すべてで、選車から出発までキーボードだけ／クリックだけで進める。
2. 作業した範囲だけが変化し、泥・泡・すすぎの違いが見える。
3. 長押しと短い複数回押しの両方で同じ範囲を完了できる。
4. 工程をまたいだ長押しで次工程を自動完了しない。
5. 途中で止めた進捗が残り、完了済み範囲を触っても壊れない。
6. 全ボディ色・ステッカーが正しい場所へ反映され、取り消しが動く。
7. 3台のお礼が異なり、仕上げ内容を保った車が出発する。
8. 一時停止で放水と音が止まり、復帰時に押下状態が残らない。
9. 再プレイと車種変更で前の車のマスク・飾りが残らない。
10. Chrome・Safari・Edgeの確認状況、画面倍率での見切れを記録する。

進捗計算・状態遷移・仕上げ履歴は小さなユニットテスト、洗浄の見え方と音はブラウザで確認する。試遊では「きれいにした場所を指差せるか」「同じ車も洗いたくなるか」を観察する。

## 11. 実装順序と公開

1. 1台・3範囲の仮素材で、道具を当てた所だけ変わる処理を作る。
2. 4工程と乾燥、長押し・短押し、入力持ち越し防止をつなぐ。
3. 色替え・ステッカー・取り消し・完成を実装する。
4. 残り2台と車種固有のお礼を加える。
5. 本番素材、泡の遊び、隠れ模様、音を組み込む。
6. 中断と再訪、実機表示を確認して試遊調整する。

既存のホームに登録し、GitHub + Cloudflare Pagesを候補に`npm run build`の`dist`を配信する。プレビューで確認後mainへ反映し、直接URLも確認する。本書作成では実装・公開を行わない。

## 12. 将来の拡張と守ること

電車、飛行機、季節の汚れ、洗車場の飾りを追加候補とする。道具を増やす前に、1回の操作で気持ちよく汚れが変わることを優先する。細かい汚れを探し続けないと終われない設計にはしない。

## 13. 初回30秒の演出と試遊での判断

車を選ぶと、最初の作業範囲は前の部分に合わせる。ホースの先がそこへ向き、「みずをかけよう」とSpaceの絵を出す。最初の0.3秒以内に泥の色が変わり、水の流れが見えるようにする。作業完了まで何も変わらない待ち時間を作らない。

前の部分を洗えたら、車が小さくお辞儀し、真ん中の泥と右矢印の絵を一度光らせる。子供が同じ場所に水をかけ続けても急かさず、5秒ほど続いたら次の範囲を輪郭で示す。次の場所への移動は本人が選ぶ。

最初の30秒で「自分が選んだ所が変わる」「道具が変わると見え方も変わる」を伝える。泡を繰り返し出したがる場合は、それ自体を楽しんでいると捉え、工程時間を短縮して先へ押し流さない。2回目は別の車の形や隠れ模様、お礼の動きが見たくなることを狙う。
