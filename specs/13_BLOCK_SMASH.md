# どっかーん！つみきタワー — 実装仕様書

作成日: 2026-11-06  
プロジェクト: child_games / 対象: PCで遊ぶ4歳児  
URL案: `/games/block-smash`  
状態: 実装前の仕様案。物理係数・時間・件数は初期値として試遊で調整する。

## 1. このゲームで届けたい体験

高く積まれたカラフルなつみきを、適当なキー入力でガラガラ崩す。少し押せば一部が傾き、連打すると大きく崩れ、押しっぱなしで風が吹く。「ここでは思いっきり壊してよい」という解放感と、崩れ方の変化を楽しむ。

壊す対象は表情のない柔らかなおもちゃだけにする。人や動物、実在の建物を壊す設定にはしない。弾数、制限時間、狙いの正確さ、命中点数、失敗は設けない。既存の「つみきのまちづくり」は建てる遊びとして残す。

## 2. 初回リリースの範囲

- 1つの箱庭ステージと、塔・橋・おもちゃのお城の3つの配置。
- 配置は毎回あらかじめ組み上がっている。建てる工程を必須にしない。
- 単打でボールまたはぷにぷにハンマー、連打で崩れの連鎖、同時押しで衝撃波、長押しで風。
- 崩れた後はつみきが自動で集まり、次の配置で何度でも続けられる。
- クリック・ポインター長押しでも遊べる3つの大きなパッド。
- 音量・ミュート・音声案内・動きを抑える共通設定。

自由な建築、武器選択、爆発・火・煙、オンライン対戦、破壊スコア、作品保存は初回に含めない。派手さは色、弾み、柔らかい衝撃音で作る。

## 3. 画面と初回30秒

中央に幅広い床と高めのつみき、下にボール・ハンマー・風の3パッドを置く。床の両端には低い壁を見せ、跳ねたつみきが場外へ消え続けないようにする。背景の装飾は少なくして崩れ方を追いやすくする。

開始時は18個程度の細い塔を表示し、「どこを おしても くずれるよ」と短く案内する。最初の入力は狙いやすい下段へ当たり、1〜3打で一部が崩れる。全部を倒せなくても、押した直後に必ず衝撃と変化を見せる。

最初の30秒で、押す→崩れる→もう一度できる、という循環を目指す。操作がなければ静止して待ち、無操作を理由に勝手に塔を崩したり次へ進めたりしない。

## 4. キー・ポインター入力

[おもちゃドラム仕様書の「入力の共通契約」](11_TOY_DRUM.md#4-入力の共通契約)を適用する。舞台フォーカス中の英字・数字・記号・テンキー・矢印・Space・Enter・削除キーを遊びに使う。Enterを押しても終了しない。

Tabは標準のフォーカス移動、Escapeは一時停止に使う。Ctrl・Command・Altとの組み合わせ、OS予約キーは奪わない。IME変換中、入力欄、設定・一時停止画面では遊びの入力を止める。開始・再開後は舞台にフォーカスを移し、ボタンをTab操作中は標準のEnter/Spaceによるクリックだけを発火する。

| 操作 | 起きること |
| --- | --- |
| 英字・数字・記号の通常打鍵 | 柔らかいボールが飛び、残っているつみきへ当たる。キー位置で左右や高さを少し変える |
| Space・Enter・矢印・削除キー | 大きなぷにぷにハンマーが出て、つみきを一度押す。キーごとに左右・上方向を固定 |
| 直近600msに5打以上 | 衝撃の輪・つみきの弾みを少し大きくする。ゲーム速度と音量は上げない |
| 80ms以内の異なる3キーの新規押下 | 通常入力に加え、床から柔らかい衝撃波を1回。最低1秒の再発火間隔 |
| 300ms以上の長押し | 対応方向から風が吹き始める。追加のボールやハンマーは自動連射しない |
| 画面パッド | ボール・ハンマーは一打、風は押している間だけ送風。クリックだけでも何度でも崩せる |

通常打鍵は押し直しだけを数え、OS repeatは無視する。連打状態は600ms内に2打以下のまま500ms続いたら解除する。同時押しを検出できない機器でも通常入力の進行を変えない。衝撃波は必須技にせず、最終的に全ての配置を通常打鍵だけで崩せる。

風の方向はキー定義に固定する。複数長押しでは力を合成するが、合計の大きさを上限で制限する。左右の風が相殺しても、風車とリボンで両方の入力が見える。全キーを離すと送風を止め、つみきの慣性だけが残る。フォーカス喪失・pointercancelなどでも送風を解除する。

## 5. 狙わなくても崩れる仕組み

画面の左右に対応するキーを押すと、その側から飛び道具が出る。標的は固定点ではなく、まだ組み上がっているつみきの中から自動選択する。前回と近い場所を優先しつつ、同じキーを繰り返しても床や空だけをたたき続けないようにする。

- ボールは180〜300ms程度で標的へ到達し、触れた位置へ衝撃を与える。発射した直後にもパッドと飛び道具が反応する。
- ハンマーは約120msで接触し、250ms程度で戻る。押し直したら前のハンマーの終了を待たず、新しい衝撃の位置を表示する。
- 1フレームに複数の打鍵が来た場合、最大3つの衝撃にまとめる。入力した側と密度を輪・リボンへ反映し、音源と物体をキー数だけ無制限に生成しない。
- 通常打鍵だけで足元の支えを順番に外せる配置にする。毎回同じ最短攻略を要求せず、押した位置に応じて崩れ方が少し変わる。
- 風はつみきを徐々に押す。力をためてから離す操作は要求せず、長押し中に変化を見せる。
- 衝撃波はつみきを少し浮かせて横へ広げる。画面全体を揺らす・白く光らせる・爆発音を鳴らす演出は使わない。

連打を止めた後に遅れて攻撃が発射されないよう、入力の待ち行列を作らない。既に飛んでいるボールとつみきの動きは自然に完了させる。

## 6. 自動で組み直す遊びの循環

各つみきは初期位置から自分の高さ以上ずれるか、30度相当の見た目の傾きを伴う崩壊状態へ移れば「崩れた」と判定する。初期位置へたまたま戻っても、その周回の判定は取り消さない。物理上の当たり判定と、見た目の傾きは分けて管理する。

80%以上が崩れた状態が300ms続いたら、その周回は十分崩れたと判断する。つみきが完全静止するまで待たない。0.8秒程度の回収演出から次の配置へ移り、塔→橋→お城→塔の順に循環する。周回数を点数として表示せず、配置の解放条件も設けない。

組み直し中にも入力を受け付ける。回収中の箱やつみきが入力に合わせて弾み、風のリボンも出る。入力を次の塔へ攻撃として予約しない。新しい配置は一度に設置し、設置完了直後から通常の攻撃を受け付ける。押し続けている風は新しい配置にも作用するため、長押しだけでも循環できる。

一時停止中は回収や配置切り替えも止まる。再開時の連続入力はリセットし、勝手に次の塔が崩れ始めない。回収済みの古いつみきは新しい物体と入れ替え、周回のたびに物体を積み増さない。

## 7. 状態と終了

| 状態 | 入力・条件 | 次の動作 |
| --- | --- | --- |
| `ready` | あそぶ | 最初の塔を表示して`smashing`へ。舞台にフォーカス |
| `smashing` | 通常打鍵・長押し | 衝撃・送風・物理更新。自由に続ける |
| `smashing` | 80%以上が崩れ300ms継続 | `rebuilding`へ |
| `rebuilding` | 約0.8秒経過 | 次の配置へ入れ替え`smashing`へ |
| 任意の遊び状態 | 設定・Escape・タブ移動・フォーカス喪失 | `paused`で物理・回収・音・入力を停止 |
| `paused` | つづきからあそぶ | 元の配置と経過時間から再開。押下集合は空 |
| 任意の状態 | 明示的にホーム | 物体・予約・音・イベントを破棄 |

完成ボタンや自動完了画面は付けず、共通の一時停止・ホームで終える。音の初期化が失敗しても物理と見た目で遊べる。休止中の実時間を物理更新へまとめて流し込まない。

## 8. 見た目・音・動きを抑える設定

つみきは角の丸い木製風・スポンジ風の6色。壊れた断面や破片は作らず、一つのつみきがそのまま転がる。ボールもハンマーも柔らかく変形して戻り、衝撃位置が分かる。

音は「ぽん」「ごろん」「からから」の短い3系統を軸にする。衝突ごとに必ず音を鳴らさず、大きな接触だけを選び、全体で毎秒8回・同時8声までに制限する。同じ物体の連続衝突音には100msの最小間隔を設ける。入力が増えてもマスター音量を上げず、無操作でも続く接触音の暴走を防ぐ。

動きを抑える設定では、連続する跳躍・回転・飛来・回収移動を使わない。衝撃の枠と、崩れる前後の配置を短い穏やかな切り替えで見せる。長押しも一定間隔の配置更新で表現する。同じ崩壊判定と周回を保ち、この設定でも塔を倒せる。通常設定でもカメラ揺れや点滅は使わない。

| 分類 | 必要なもの |

| ステージ | 床、低い側壁、回収箱、淡い背景 |
| つみき | 6色の丸角長方形、橋用の長いつみき、屋根の飾り |
| 道具 | 柔らかいボール、ぷにぷにハンマー、風車・リボン |
| UI | 3パッド、簡略キーボード図、ホームカード |

SVGまたはCanvasの図形で描く。屋根などの装飾が当たり判定と大きく違って見えないよう、初回は単純な形へ寄せる。プレイ中の外部素材取得や画像生成は行わない。

## 10. 実装構成・物理・負荷の上限

- 画面案: `src/games/BlockSmash.tsx`。共通入力は `useMashInput`、一時停止は `usePlay` に接続。
- 物理案: `src/blockSmashPhysics.ts`。初回は円のボールと軸に平行な長方形のつみきによる2D衝突を採用し、つみきの回転は見た目の演出に限定する。精密な剛体シミュレーションを受け入れ条件にはしない。
- `SmashState`: phase、layoutId、cycleId、bodies、projectiles、collapsedIds、collapseHoldTime、rebuildElapsed、heldWind、effects。
- 配置は18〜30個、つみきの総上限36個、飛び道具6個、装飾60個。ハンマーは衝撃イベントとして扱い、永続する物体にしない。
- 物理は1/60秒の固定刻み、1描画フレームの追従更新は最大4回。負荷時は余分な時間を捨て、復帰直後の巨大な移動を防ぐ。
- 重力・反発・摩擦・最大速度を設定値へまとめる。移動の速いボールは線分で衝突を調べ、細いつみきをすり抜けにくくする。
- つみき同士の衝突・支えを処理する。床上で低速が500ms続けば休止し、新しい接触で起こす。微小振動で音を鳴らし続けない。
- 床の下や大きな画面外へ出た物体は除去し、つみきなら崩壊済みとして扱う。NaNや非有限値を検出した物体も同様に回収し、周回不能にしない。
- 動く状態は専用エンジンで更新し、毎フレーム全物体をReactの状態へコピーしない。描画はCanvas、UIはReactで構成する。
- 初期配置の安定性を先に確認する。無操作で倒れる配置は採用せず、支えを抜いた時に崩れることを重視する。

## 11. 受け入れ条件

1. どの対象キーからでも一打目に反応し、最初の塔は1〜3打で変化が分かる。Enter連打でも終了しない。
2. 同じ通常キーだけで3配置とも崩せる。標的が空や床へ固定されず、狙い直しを要求しない。
3. OS repeatは攻撃を増やさず、300ms後に風へ変わる。解放・一時停止・離脱で風と入力状態が残らない。
4. 同時押しの再発火間隔を守り、連打中にも物理更新と新しい反応が続く。
5. 80%・300msの判定で一度だけ組み直しが始まり、回収中の入力にも反応する。次の塔へ溜まった攻撃を発射しない。
6. 無操作30秒で3配置ともほぼ安定する。床への沈み込み、壁抜け、永久振動が進行を妨げない。
7. 毎秒20回相当の入力を30秒続けても上限を超えず、手を止めた後に新しい攻撃を生成しない。
8. 5分または20周回の長い方を試し、物体・装飾・音源数が累積しない。極端な速度や非有限値でも次の周回へ復帰できる。
9. クリックだけ、ミュート、動きを抑える設定、Tab操作で開始・自由遊び・一時停止・ホームへ移動できる。
10. 1280×720、1366×768、1024×768、Chrome・Safari・Edgeで表示・入力・音を確認し、検証できた範囲を記録する。

衝突・崩壊判定・周回状態・上限・中断復帰を自動テストで確認する。崩れ方の手応え、音の気持ちよさ、酔いやすい動きの有無は実ブラウザで確認する。

## 12. 試遊・実装順序と公開

まず仮の四角と丸で、支えが外れると崩れること、同じキーだけで次の配置へ進めること、無操作では勝手に倒れないことを検証する。その後、共通入力・送風・同時押し、回収と配置の循環、アートと音、各種中断処理の順に加える。

試遊で反応が小さい場合は、強い音や揺れを足す前に当たる場所と崩れやすさを調整する。組み直しで手が止まる場合は回収を短くし、回収中の反応を分かりやすくする。速すぎて見えない場合は最大速度と反発を下げる。

子どもとの試遊では、崩れた後に自分からもう一度押すか、少しだけ倒す・一気に倒すを試すか、組み直しを待ち時間と感じるかを見る。強くたたくよう促さず、軽い打鍵で十分に大きな反応を返す。

本書は仕様の作成のみ。実装時はPRで変更を提示し、対象PRへのユーザー承認なしにマージ・自動マージ・例外操作をしない。ゲームサイトの配信・公開URLは別途確認する。

## 13. 後回しにする拡張

スポンジやゼリーなど素材の違い、配置の追加、任意の簡単な建築を候補とする。複雑な物理や配置数を増やす前に、どんな入力でも反応して繰り返せることを磨く。


## 14. 実装状況（2026-11-06）

3配置・自動照準・風・同時押し・80%崩壊後の自動組み直しを実装。物理は矩形の簡易衝突で、回転は見た目のみ。ボールとハンマーは命中位置の即時演出で、発射から命中までの軌道演出は未実装。
