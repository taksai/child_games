# どうぶつバンド — 実装仕様書

作成日: 2026-11-04  
プロジェクト: child_games / 対象: PCで遊ぶ4歳児  
URL案: `/games/animal-band` / 状態: 実装前の仕様案。時間・音量・配置は試遊で調整する。

## 1. このゲームで届けたい体験

自分が押したキーで動物が音を鳴らし、ひとりだった演奏がにぎやかなバンドになる。「音楽を正しく演奏する」より、「ぼくがみんなを集めて、この音楽を作った」という感覚を主役にする。

最初は静かなステージにゾウが一頭。太鼓を鳴らすと、舞台裏から他の動物が顔を出す。好きな仲間を呼び込み、最後は自分のバンドがお客さんの前でパレードする。

面白さの核は、キーを押した瞬間の反応、音が重なる発見、動物同士の掛け合い。正解、リズム判定、点数、失敗は設けない。

## 2. 初回リリースの範囲

- 1ステージ、5種類の動物・楽器、自由なメンバー構成。
- 同じ曲に合わせて作った5本の演奏ループ。どの組み合わせでも成立する。
- メンバー追加・お休み、自由な合いの手、約13秒の完成パレード。
- 1回2〜4分程度。自由演奏を続ける時間には制限を設けない。
- 音量・音声案内・動きを抑える設定。音なしでも各楽器の反応が分かる。

録音、楽譜、音程入力、曲の自動生成、マイク、外部音楽サービスは初回に含めない。

## 3. 画面とアート

| 場面 | 見た目と役割 |
| --- | --- |
| ホームカード | 太鼓をたたくゾウと跳ねる音符。カード全体を押すと開始 |
| 招待 | 遊園地の小さな屋外ステージ。「バンドをつくろう！」 |
| 自由演奏 | 中央に5つの演奏場所、下に動物の顔と対応キー。お休み中も顔を表示 |
| パレード | 今いる動物が列になり、観客の前を演奏しながら進む |
| おひろめ後 | バンドの集合写真風の静止画。「またえんそう」「ホーム」 |

赤・黄色・ターコイズを中心にしたサーカス風。音符は音量計の代わりに上下し、打楽器は丸、低音は太い波、ベルは星で音の違いを可視化する。動物の顔・楽器・キーの対応は画面を通して変えない。

## 4. 進行と状態

| 状態 | 入力・条件 | 反応・次の状態 |
| --- | --- | --- |
| `ready` | 再生ボタン | 音を初期化し、ゾウが小さくお辞儀。`jam`へ |
| `jam` | 1〜5 | 対応する仲間が参加／お休み。自由演奏を続ける |
| `jam` | Space | 全員がジャンプし、短い合いの手。メンバーは変えない |
| `jam` | Enter／パレード | 現在の編成を固定し、次の小節で`parade`へ |
| `parade` | 約10秒の行進＋約3秒の締め | 参加動物が演奏。最後に観客が拍手して`complete`へ |
| `complete` | もう一度 | 編成を保ったまま`jam`へ。初めからボタンでは全員お休みに戻す |

パレードに入る前は音が止まらない。全員お休みなら、舞台の小鳥が口笛を吹いて行進を先導し、空の編成でも完成できる。参加数を増やすことを成功条件にしない。

## 5. 操作

| キー | 動物と楽器 | 押した瞬間の視覚反応 |
| --- | --- | --- |
| 1 | ゾウ：太鼓 | 耳が広がり、太鼓の皮がぷにっと沈む |
| 2 | クマ：ベース | お腹と弦がぼよんと揺れる |
| 3 | サル：ギター | しっぽでポーズ、弦から色の線が出る |
| 4 | ペンギン：ラッパ | 頬がふくらみ、丸い音符が飛ぶ |
| 5 | ウサギ：ベル | 耳が跳ね、星がふわっと出る |
| Space | 合いの手 | 全員ジャンプ。短い「ヘイ！」または拍手 |
| Enter | パレードへ | 大きな旗が開く |

画面上の動物カードでも同じ操作ができる。数字が読めなくても、キーボード上段の絵と光る位置で探せる。長押しのリピートは無視し、切り替え要求は最新の状態にまとめる。

## 6. 面白さを支える音と仕掛け

- 曲は96 BPM・4拍子・4小節の約10秒を初期案とする。全パートを同じテンポ、調、長さで制作する。
- 参加操作には即座に動物の動きを返し、演奏音は次の拍から曲の位相に合う位置で入る。曲頭への巻き戻しをしない。
- お休みは短いフェードで自然に消す。動物は退場せず、隣の演奏を楽しそうに聞く。
- 初めて3頭がそろうと、観客のひよこが踊り出す。一度だけ起こる飾りの演出で、操作を止めない。
- ゾウとクマがいると目を合わせ、サルとウサギがいると同じポーズをする。音楽を崩さず、組み合わせの発見を増やす。
- 合いの手は最低600ms間隔とし、連打で耳障りな音が重ならない。演奏そのものは途切れない。
- 音声案内は最初の「どうぶつのキーをおしてね」とパレード案内を中心にし、自由演奏へ何度も割り込まない。

## 7. 必要な素材

| 分類 | 内容 |
| --- | --- |
| 背景 | ステージ、幕、行進用の道、観客席 |
| 動物 | 5頭それぞれの待機・演奏・お休み・歩く・決めポーズ。目や耳は分離して動かす |
| 楽器 | 太鼓、ベース、ギター、ラッパ、ベル。持ち手や支点を統一 |
| 演出・UI | 音符、波、星、旗、拍手するひよこ、キー表示、参加中の印 |
| 音 | 同期ループ5本、合いの手、参加・休止の控えめな効果音、拍手、短い音声 |
| ホーム | 透過キャラクターを使ったサムネイル |

画像は透過WebP/PNG、精密なUIはSVG。ループ音源は前後の無音と長さをそろえ、ブラウザでの継ぎ目を確認する。専用ループがBGMを兼ねるため、別のBGMを重ねない。

## 8. 技術構成とデータ

React + TypeScript + Viteで共通サイトに追加する。動物と楽器はDOM画像とCSSアニメーション。音はWeb Audioの共通クロックを使い、描画フレームを音のタイミングの基準にしない。

- `BandState`: phase、activeAnimalIds、pendingAnimalStates、paradeLineup、paused。
- `AnimalDefinition`: id、key、instrument、stemUrl、animationFrames、stagePosition。
- `Transport`: BPM、小節長、開始時刻、停止までの経過時間、予約済み音源。
- ゲーム進行は`useReducer`、音源の予約・停止は専用モジュールで管理。状態変更時に音源ノードを重複生成しない。
- 各パートのゲインをそろえ、5本同時再生でもクリッピングしないヘッドルームを設ける。
- 素材と音源は開始前に読み込む。音の初期化に失敗したら再試行ボタンと視覚だけで遊ぶ選択肢を出す。

配置案: `src/games/animal-band/{AnimalBandGame.tsx,reducer.ts,config.ts,audioTransport.ts,components/,styles.css}`、素材は`public/assets/animal-band/`。設定だけを端末内に保存し、録音や通信はしない。

## 9. 共通UI・一時停止・エラー

主要ボタンは64px以上を目安にし、1366×768でステージと操作が収まる。短いひらがなと絵で案内する。キー処理はゲーム画面内だけで有効とし、ボタンの標準操作と二重発火させない。

設定表示・タブ移動・フォーカス喪失で音とアニメーションを一時停止し、押下状態を消す。再開ボタンで音声コンテキストを復帰させ、全パートを同じ位相で再開する。ホームへ戻る際は予約・音源・イベントを破棄する。ミュートは編成を消さず、音声案内中は演奏を控えめにする。

## 10. 受け入れ条件と確認

1. 1頭だけでも5頭でも演奏が成立し、長く再生してもパートがずれない。
2. 操作直後に動物が反応し、参加音は次の拍で正しい位置から入る。
3. 参加とお休みを素早く切り替えても二重再生や音の残留がない。
4. 合いの手連打でも音割れせず、演奏が止まらない。
5. 全員お休みでもパレードを完成できる。
6. キーボードだけ／クリックだけで開始、編成、完成、再プレイできる。
7. 一時停止・再開後に音と動物の拍が大きくずれない。
8. 音なしでも参加者と操作への反応が分かる。
9. ホームへ戻った後に音が鳴らず、再訪しても演奏が重複しない。
10. Chrome・Safari・Edgeで音の開始と復帰を確認し、実際に確認できた環境を記録する。

編成変更と位相計算は少数のユニットテスト、音の継ぎ目と聞こえ方はブラウザで確認する。試遊では「押した楽器が分かるか」「自分から組み合わせを変えるか」を観察する。

## 11. 実装順序と公開

1. 5頭の静的ステージと、キーに反応する仮アニメーションを作る。
2. 2本の仮ループで同期・参加・休止・一時停止を先に検証する。
3. 5楽器、自由演奏、合いの手、完成パレードを接続する。
4. 本番イラストと音源、動物同士の掛け合いを入れる。
5. 音量を調整し、再生・停止・再訪とPC表示を確認する。
6. 試遊で反応速度と案内量を調整し、ホームに登録する。

既存方針どおりGitHub + Cloudflare Pagesを候補とし、`npm run build`の`dist`を配信する。PRプレビューで確認後にmainへ反映し、直接URLの再読み込みも確認する。本書作成では実装・公開を行わない。

## 12. 将来の拡張と守ること

季節の曲、楽器の入れ替え、昼と夜のステージ、短い演奏の保存を候補とする。初期版では「上手に押せたか」で評価せず、どんな編成にもちゃんとしたお披露目を返す。

## 13. 初回30秒の演出と試遊での判断

最初の画面にはゾウだけを大きく出し、演奏メンバーはまだ0頭にする。開始後は太鼓の絵と1キーを一度だけ弾ませる。1を押すと耳と太鼓が即座に動き、曲が始まる。他のキーを先に押しても、その動物から同じように始められる。

最初の音が鳴ると、舞台裏の4頭が「いれて！」と顔を出す。長い説明は挟まない。1→3→5と押せば音が増え、もう一度3でサルだけがお休みになる。この「増える／減る」が耳と絵の両方で伝わることを、最初の30秒の目標にする。

10秒ほど操作がなければ、参加していない動物のカードが1枚だけ手を振る。自動で加入させたり、完成へ進めたりしない。試遊で子供が違いを聞く前に次々押す場合は、操作を遅くするのではなく楽器の音色差と動きの差を大きくする。2回目は編成の違いを試したくなることを優先し、曲数の追加で補わない。
