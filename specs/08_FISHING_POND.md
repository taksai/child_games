# ぷかぷかつりぼり — 実装仕様書

作成日: 2026-11-04  
プロジェクト: child_games / 対象: PCで遊ぶ4歳児  
URL案: `/games/fishing-pond` / 状態: 実装前の仕様案。待ち時間・合図の長さは試遊で調整する。

## 1. このゲームで届けたい体験

浮きを見ながら「そろそろかな」と待ち、大きく沈んだら引く。水面から何かが飛び出す瞬間と、釣った生き物が自分の水槽で泳ぎ始める喜びをつなげる。

魚だけでなく、長靴や宝箱も釣れる。長靴は洗うと花の鉢になり、宝箱は水槽の飾りになる。外れとして捨てる物を作らず、何が釣れても水槽が少し豊かになるようにする。

## 2. 初回リリースの範囲

- 1つの池、空想の魚6種類、長靴と宝箱の計8種類。
- 釣り糸を垂らす→待つ→合図で引く→釣果を見る→水槽に迎える。
- Spaceまたは大きなボタン1つが中心の操作。
- 魚を見て楽しむ水槽と、砂・水草・飾りを変える簡単な模様替え。
- 1回3〜5分、3匹程度で水槽を見る流れを案内。1回で最大8回釣れる。

釣り竿の強化、お金、魚の売却、逃げる魚、狭い成功タイミング、放置中の進行は初回に含めない。

## 3. 画面・アート

| 場面 | 内容 |
| --- | --- |
| 池 | 水面を大きく取り、浮きを中央に表示。足元には集まった釣果の絵 |
| 釣れた瞬間 | 水しぶきと一緒に釣果を拡大。種類ごとの短い動き |
| 水槽 | 釣った魚が泳ぎ、長靴の鉢や宝箱が並ぶ。下に3つの模様替えボタン |
| 記念画面 | 水槽の全景。「もっとつる」「すいそうであそぶ」「ホーム」 |

水色・緑・コーラル色の明るい池。水中の影はかわいく、針が魚に刺さる描写はしない。引き上げた魚は短い演出ですぐ水槽へ移り、苦しむ表現を使わない。

## 4. 進行と状態

| 状態 | 入力・条件 | 反応と次の状態 |
| --- | --- | --- |
| `ready` | 再生 | 池と道具を表示し`idle`へ |
| `idle` | Space／つる | 糸を垂らし`waiting`へ |
| `waiting` | 約2〜4秒 | 小さな波紋の後、浮きが大きく沈み`bite`へ |
| `waiting` | 早めのSpace | 浮きが小さく跳ねるだけ。糸は戻さず待ち続ける |
| `bite` | Space／ひく | 約2秒の引き上げ演出を経て`catchReveal` |
| `bite` | 約4秒を過ぎる | 魚を失わず、少し間を置いて再び合図 |
| `catchReveal` | 約3秒／演出後の次へ | 釣果を記録し`idle`へ。8回目なら水槽へ |
| `idle` | Enter／すいそう | 現在の釣果を保って`aquarium`へ |
| `aquarium` | Enter／しゃしん | `complete`へ |

釣れる合図を待って引く形は保つが、合図を逃しても同じ釣果がまた食いつく。釣りの途中で水槽へ行くボタンを押した場合は、釣果を記録せずその投下だけ中断する。

## 5. 操作と合図

| 場面 | キー | 内容 |
| --- | --- | --- |
| 池 | Space | 投下／合図で引く。1押下1操作 |
| 池 | Enter | 水槽へ |
| 水槽 | 1 | 砂の見た目を3候補で切り替え |
| 水槽 | 2 | 水草の配置を3候補で切り替え |
| 水槽 | 3 | 飾りの配置を切り替え。未入手なら石の飾りを使う |
| 水槽 | Space | 泡を出す。魚が近づいて遊ぶ |
| 水槽 | Enter | 記念画面へ |

待つ間の小さな波紋と、釣れる時の大きな沈み込みを明確に分ける。合図は浮きの動き、魚の絵、Spaceの拡大、短い音で重ねて伝える。赤や緑だけで判別させない。早押しに大きな失敗音や叱る音声を返さない。

## 6. 釣果と水槽の楽しさ

- 1セッションの釣果は8種類を1回ずつ含む袋として開始時にシャッフルする。最初の1回は必ず魚にし、次に何が来るかは分からないが全種類を迎えられる。
- 釣果は投下時に予約し、早押しや合図の見逃しで抽選し直さない。中断して水槽へ行った場合も次の投下で同じ候補を使う。
- 魚は、丸い金色、しましま、ふくらむ、ひらひら、葉っぱ形、星模様の6種。各魚の色・輪郭・泳ぐ動きを変える。
- 長靴が釣れたら水がぽとぽと落ち、次に見ると花が咲いて鉢になる。宝箱は魚が顔を出せる隠れ家になる。
- 3回釣ったら一度だけ水槽ボタンを穏やかに案内し、続行を妨げない。
- 水槽のSpaceで泡を出すと、魚が一斉ではなく近い順に寄ってくる。ふくらむ魚は丸くなり、星模様は回って見せる。
- 水槽内の移動は見た目だけに使い、餌・空腹・死亡・容量不足を管理しない。
- 釣果0でも水槽へ行ける。泡と石で遊べ、記念画面を作れる。8回後は無限に釣らせず、水槽での遊びへ自然につなぐ。

## 7. 必要な素材

| 分類 | 素材 |
| --- | --- |
| 池 | 背景、釣り竿、糸、浮き、波紋、魚影、水しぶき |
| 釣果 | 魚6種の本体・泳ぎ・反応、長靴と花鉢、宝箱の開閉 |
| 水槽 | 本体、砂3候補、水草3配置、石、飾りの位置、泡 |
| UI | 投下・引くの絵、合図、釣果の小さな絵、水槽、模様替え、記念枠 |
| 音 | 投下、水面、合図、引き上げ、魚ごとの反応、長靴、宝箱、泡、案内、BGM |

透過WebP/PNGとSVGを使い、水面と糸の基準位置をそろえる。釣果の拡大は原画がぼけない解像度を用意する。待つ間の環境音は合図を隠さない音量にする。

## 8. 技術構成とデータ

React + TypeScript + Vite。浮き、糸、魚、水槽はDOM画像とCSSアニメーションで表現する。

- `FishingState`: phase、catchBag、catchIndex、reservedCatchId、collectedIds、waitElapsed、biteElapsed、aquariumStyle。
- `CatchDefinition`: id、kind、revealAnimation、aquariumAsset、swimPattern、reaction。
- 投下ごとに待ち時間を決定し、アクティブ経過時間で合図へ遷移する。
- 釣果の記録は引き上げ完了時に1回だけ行い、再描画や入力で増えないようにする。
- 水槽は最大6魚＋2飾りで、泳ぐ範囲と前後関係を定義する。魚同士の物理衝突は不要。
- 泡の同時数に上限を設け、長時間遊んでもDOM要素を増やし続けない。

配置案: `src/games/fishing-pond/{FishingPondGame.tsx,reducer.ts,catches.ts,Aquarium.tsx,components/,styles.css}`。素材は`public/assets/fishing-pond/`。釣果はセッション中のみ保持する。

## 9. 子供向けUI・中断

Spaceと画面の大きなボタンは同じ処理を呼ぶ。押しっぱなしのリピートを無視し、投下時の入力が引く操作に持ち越されないようにする。1366×768でも浮きと合図が大きく見える。主要ボタンは64px以上を目安にする。

設定・タブ移動・フォーカス喪失で待ち時間、合図、魚、音を止め、再開を待つ。中断中に合図が終わらない。ページ離脱時に演出と音を破棄。素材先読みの失敗は再試行で回復する。音なしでも釣れるタイミングが分かる。

## 10. 受け入れ条件

1. Spaceだけで投下・合図待ち・引き上げを行える。
2. 早押しと合図の見逃しでも釣果を失わず、再び合図が来る。
3. 最初は魚、8回以内に全8種という釣果のルールを満たす。
4. 合図中の連打でも釣果が二重記録されない。
5. 途中で水槽へ行っても次の釣果が勝手に変わらない。
6. 長靴と宝箱が水槽の飾りになり、魚6種の反応も異なる。
7. 0回でも水槽と記念画面へ進め、8回後も水槽で遊べる。
8. キーボードだけ／クリックだけで一巡できる。
9. 一時停止・再開・新しい池でタイマーや魚が重複しない。
10. 音なし、倍率変更、Chrome・Safari・Edgeの確認状況を記録する。

釣果袋、合図の遷移、二重記録防止をユニットテスト。浮きの分かりやすさと魚の動きはブラウザで確認する。試遊では「小さい波と釣れる合図を見分けるか」「水槽を自分から見に行くか」を観察する。

## 11. 実装順序と公開

1. 浮き1つで、投下・待つ・引く・見逃しからの再合図を作る。
2. 仮の魚で引き上げと水槽への移動をつなぐ。
3. 8種の釣果袋、長靴・宝箱、模様替えを入れる。
4. 魚ごとの泳ぎと泡への反応、記念画面を作る。
5. 本番素材・音、中断・再プレイを確認する。
6. 試遊で合図の長さと待ち時間を調整し、ホームに登録する。

GitHub + Cloudflare Pagesを候補とし、`npm run build`の`dist`を配信。プレビュー後mainへ反映し、直接URLも確認する。本書作成では実装・公開を行わない。

## 12. 将来の拡張と守ること

季節の池、魚の追加、水槽の保存を候補にする。難しいタイミングで魚を逃がすより、「待って、見て、自分で引いた」という手応えを守る。珍しさだけで繰り返しを促さず、普通の魚にも固有の楽しさを持たせる。

## 13. 初回30秒の演出と試遊での判断

開始時は浮きを手元に置き、Spaceの絵と「なげてみよう」。最初の投下は待ち時間を2秒程度に固定し、小さな波紋から大きな沈み込みへ明確に変える。初回だけ特別に自動成功させず、本人の引く操作を待つ。

合図を逃しても浮きは戻り、次の沈み込みが来る。「にげちゃった」と言わず、魚影が近くを回っている絵で待ってくれていることを伝える。釣れた魚は見せた後、小さな水槽の窓へ泳いで入り、もう一度会えることを示す。

最初の30秒で1匹を迎えられるテンポを目指す。早押しが続く場合はペナルティを追加せず、浮きの沈み幅とSpaceの案内を見直す。2回目は新しい釣果への期待に加え、前に迎えた魚が泡でどう遊ぶかを見に戻りたくなることを狙う。
