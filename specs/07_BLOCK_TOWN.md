# つみきのまちづくり — 実装仕様書

作成日: 2026-11-04  
プロジェクト: child_games / 対象: PCで遊ぶ4歳児  
URL案: `/games/block-town` / 状態: 実装前の仕様案。マス数・演出時間は試遊で調整する。

## 1. このゲームで届けたい体験

家を置いたら誰かが窓を開け、パン屋を置いたら煙突からパンの形の雲が出る。道をつないで「うごかす」を押すと、自分の町をバスが走る。

置いた物は飾りではなく、小さな暮らしの始まりになる。道路がうまくつながらなくても町は成立し、家や池はそれぞれ反応する。「この先に道を足したら、バスが来るかな？」と試せる構成にする。

## 2. 初回リリースの範囲

- 6列×4行の平面グリッド。固定のバス車庫と出入口の道を配置する。
- 道・家・木・パン屋・池の5パーツと、消す道具。
- 道は隣接状況から直線・曲がり角・分岐へ自動で形を変える。
- 自分の町が約15秒動く時間と、完成した町の記念画面。
- 取り消し、編集への復帰、3つの見た目違いの家。
- 1回3〜7分程度。制作時間、必要な建物数、成功条件は設けない。

資金、人口、交通渋滞、建物の高さ、道路の手動回転、永続保存は初回に含めない。

## 3. 画面・見た目

| 場面 | 内容 |
| --- | --- |
| 制作 | おもちゃのボードを少し上から見る。中央にマス、下にパーツ、上にうごかすボタン |
| プレビュー | 選択マスに半透明の完成予想。置ける場所が輪郭で分かる |
| 町が動く | 枠線を薄くし、バスと住人、鳥、池のアヒルが動く |
| 記念画面 | 町全体を絵はがき風に表示。「つづきをつくる」「もういちどうごかす」 |

木製積み木の形に、赤・黄色・ミント・水色の明るい塗装。パーツは1マスに収まり、背の高い木も隣のマスを隠しすぎない。格子は目立たせすぎず、選択マスと置ける印を強くする。

## 4. 進行と操作

| 状態 | 入力・条件 | 反応と次の状態 |
| --- | --- | --- |
| `ready` | 再生 | 車庫から運転手が手を振り`building`へ |
| `building` | 1〜5／パーツカード | 次に置くパーツを選ぶ |
| `building` | 矢印／マスをクリック | カーソルと完成予想を移す |
| `building` | Space／おく | 選択マスに配置し、パーツ固有の反応 |
| `building` | 6／消す道具→Space | 選択マスのパーツを消す |
| `building` | Enter／うごかす | 町を固定し`living`へ |
| `living` | 約15秒／Enter | 町が動いた後、`postcard`へ |
| `postcard` | 続き／もう一度 | 編集へ復帰／同じ町で再び動く |

クリック操作はパーツ選択後、マスをクリックすると配置する。ホバーではプレビューだけ出し、クリック1回を1操作とする。キーボードは矢印で場所を選びSpaceで置く。2つの方法で同じ配置処理を呼ぶ。

## 5. 配置・取り消しのルール

- 1マス1パーツ。別種類を置くと置き換わり、元のパーツは1回の取り消しで戻る。
- 家を同じマスにもう一度置くと、屋根や窓の違う次の家へ切り替わる。道路など同じ状態への操作は履歴を増やさない。
- 固定の車庫と出入口は消せない。触ると運転手が手を振り、失敗音は出さない。
- 道を置く・消すたび、周囲4方向の道路の見た目を更新する。回転キーは要求しない。
- 「ひとつもどす」は配置・上書き・削除を操作単位で戻す。最大50操作。
- 「ぜんぶやりなおす」は絵付きの確認後に固定の車庫だけの状態へ戻す。
- パーツを置くたび短いごほうびを返す。家は窓、木は鳥、パン屋は煙、池は水の輪。町を動かすまで無反応にしない。

## 6. 町が動く仕組み

- バスは車庫と上下左右でつながる道路だけを走る。斜めにはつながらない。
- 行き止まりでは向きを変えて戻る。ループ道路も分岐も扱い、道のない場所へ瞬間移動しない。
- 分岐では未訪問の道を優先し、戻りながら別の道へ進む。15秒で全道路を巡りきる必要はない。
- 走っている道路に隣接する家やパン屋で短く停車し、住人が手を振る。乗客の人数管理は設けない。
- 車庫から先へ道がない場合も、運転手が車庫の前で手を振る。家の窓、木の鳥、池のアヒルは独立して動く。
- パン屋の隣に木があると鳥がパンを見に来る、池が2つ並ぶとアヒルが同時に揺れるなど、小さな組み合わせ演出を2種類入れる。
- 動いている間のSpaceはやさしいベル。連打制限を設け、道路や建物を編集しない。
- 建物の数を点数にしない。何も置いていない町も記念画面へ進める。

## 7. 必要な素材

| 分類 | 素材 |
| --- | --- |
| ボード | 背景、24マス、選択枠、置く前の半透明表示 |
| 建物 | 固定車庫、家3種、木、パン屋、池。動く窓・鳥・煙・アヒル |
| 道路 | 単独、終端、直線、曲線、T字、十字。接続方向から回転して使用 |
| 乗り物 | バス4方向、運転手、停車と方向転換の差分 |
| UI | 5パーツ、消す道具、取り消し、動かす、記念枠、キー図 |
| 音 | 置く・消す、建物別の反応、バス、ベル、記念画面、案内、BGM |

透過WebP/PNGとSVGを使用し、道路の接続端とグリッド境界を一致させる。車輪や鳥の動きは分離パーツで作る。資産サイズよりマスの基準座標を優先してそろえる。

## 8. 技術構成とデータ

React + TypeScript + Vite。配置はDOMグリッド、バスはグリッド上の論理座標に沿ってtransformで補間する。

- `TownState`: phase、grid、cursor、selectedTool、history、simulationSnapshot。
- `Tile`: kind、variantId。固定タイルかどうかはボード定義で管理する。
- `RoadGraph`: 道路マスの4方向隣接グラフ。車庫からの到達可能集合を計算する。
- `BusRoute`: 到達可能道路の探索順と戻り道。最大48辺程度の有限経路にし、再生時間で表示を区切る。
- 編集中だけグラフを再計算し、動作中は固定スナップショットを使う。
- 道路の向きは上下左右の接続ビットから決定し、図の向きと実際の接続をそろえる。

配置案: `src/games/block-town/{BlockTownGame.tsx,reducer.ts,tiles.ts,roads.ts,simulation.ts,components/,styles.css}`。素材は`public/assets/block-town/`。町はセッション中のみ保持する。

## 9. 子供向けUI・中断

1366×768でも全24マスとパーツを表示し、マスはおおむね80px以上を確保する。道具の選択は色枠だけでなく、持っている絵とカーソル形状にも反映する。全ボタンはTabでも使える。

設定・タブ移動・フォーカス喪失でバスと生き物と音を停止する。復帰は再開ボタンを待つ。ホームに戻るとフレームループを破棄。音なしでも配置と訪問が分かる。素材の先読み失敗時は再試行を出す。

## 10. 受け入れ条件

1. 全マスをキーボードで選択でき、クリックでも同じパーツを配置できる。
2. 上書き・削除・家の切り替えを操作単位で戻せる。
3. 道路の見た目と4方向の接続判定が一致する。
4. 車庫からつながっていない道路へバスが飛ばない。
5. 行き止まり・ループ・分岐で停止や無限経路生成が起きない。
6. 道がなくても町の反応と記念画面が成立する。
7. 動作中に編集状態が変わらず、編集復帰時に作った町が残る。
8. 連打・全マス配置・削除後でも重い処理や音の重複がない。
9. 中断・再開とホーム再訪でバスが増えない。
10. 音なし、表示倍率、Chrome・Safari・Edgeの確認状況を記録する。

道路接続、探索経路、履歴をユニットテストし、マスと道の位置合わせをブラウザで確認する。試遊では「バスが来るように道を足すか」「建物の反応を見るために配置を変えるか」を観察する。

## 11. 実装順序と公開

1. 24マスに置く・消す・戻す処理を作る。
2. 道路の自動接続と車庫からの到達可能判定を実装する。
3. 行き止まり・分岐・ループで動くバスを先に確認する。
4. 建物ごとの反応、組み合わせ演出、記念画面を加える。
5. 本番画像・音、中断・再訪・表示倍率を確認する。
6. 試遊でマスの大きさと動作時間を調整し、ホームに登録する。

GitHub + Cloudflare Pagesを候補とし、`npm run build`の`dist`を配信。プレビュー後mainへ反映し、直接URLも確認する。本書作成では実装・公開を行わない。

## 12. 将来の拡張と守ること

橋、電車、夜の町、町の保存を候補にする。配置ルールを増やす前に、置いた物がすぐ反応することを守る。道を正しくつながないと何も起きない町にはしない。

## 13. 初回30秒の演出と試遊での判断

固定の車庫は左端の中央寄りに置き、出入口の道を右へ1マス伸ばす。最初のカーソルはその右隣、道具は道路を選択しておく。Spaceを押すだけで道が延び、車庫のバスが嬉しそうに前へ出る。最初の成功を道路選択や回転の説明で遠ざけない。

次は家のカードが一度だけ揺れる。家を選んで置くと、すぐ窓が開き住人が手を振る。道の上に家を置いた場合も上書きとして成立し、後で戻せる。最初の30秒で「置くと町が反応する」を感じられればよい。

試遊で道路だけを伸ばす子には、そのまま長い道を走る楽しさを返す。家ばかり並べる子にも窓や住人の演出を返す。2回目はバスの通る場所を変える、池を並べるなど、自分の意図が町の動きに反映されることを狙う。
