# かげえのおとしもの — 実装仕様書

作成日: 2026-11-04  
プロジェクト: child_games / 対象: PCで遊ぶ4歳児  
URL案: `/games/shadow-lost-found` / 状態: 実装前の仕様案。問題数・難度は試遊で調整する。

## 1. このゲームで届けたい体験

動物が見せる影の形を見て、忘れ物を探す。傘を渡したら雨の中でくるっと開き、鍵を渡したら小さな家のドアが開く。選択肢を当てて終わるのではなく、「これを渡したら何が起きるかな？」と次の場面を楽しみにできるゲームにする。

形をじっくり比べても急かされない。間違いは動物がやさしく返し、迷ったら輪郭のヒントが増える。読み書きや物の名前を知っていることは要求しない。

## 2. 初回リリースの範囲

- 12組の「動物・忘れ物・お礼の小劇」。1回に5組を出題する。
- 前半2組は候補2つ、後半3組は候補3つ。
- 正面または横から見た、そのままの向きのシルエット照合。
- 間違い回数に応じた輪郭ヒントと、手動のヒントボタン。
- 5組が集まる完成画面。1回3〜5分程度。

文字入力、物の名前の暗記、制限時間、減点、左右反転や回転した難問は初回に含めない。

## 3. 画面・アート

| 場面 | 内容 |
| --- | --- |
| 受付 | 木陰の落とし物屋さん。動物が絵の吹き出しを持って来る |
| 探す | 中央に影、下に2〜3個の大きな候補。動物は影を指して待つ |
| 渡す | 選んだ物が動物の手元へ移る。違えばやさしく戻る |
| お礼の小劇 | 同じ画面の背景が少し開いて、忘れ物を使う短い場面 |
| 完成 | 助けた5組が、渡した物と一緒に並ぶ。押すと小さく反応。「べつのおきゃくさん」「ホーム」を表示 |

黄色い日よけ、空色の棚、ピンクの看板でポップなお店にする。影は黒に近い紺、候補は明るい色。影と選択肢の背景は十分な差を付け、輪郭がつぶれないようにする。

| クマ | 帽子 | 風で浮いた帽子を鼻に載せてポーズ |
| ネコ | スプーン | プリンをひと口食べて、しっぽがハートになる |

| ペンギン | 鍵 | 氷のおうちを開けると小さな明かりがつく |
| キツネ | ベル | お店のベルを鳴らすと仲間が顔を出す |
| ゾウ | ラッパ | 鼻で構え、丸い音符を3つ飛ばす |
| リス | 星の杖 | どんぐりがふわっと星の形に並ぶ |

## 5. 進行・操作

| 状態 | 入力・条件 | 反応と次の状態 |
| --- | --- | --- |
| `ready` | 再生 | お店が開き、最初の動物が来る。`question`へ |
| `question` | 1〜3／候補の絵 | 選んだ物を渡し`checking`へ |
| `checking` | 正解 | 影と絵が重なり、`story`へ |
| `checking` | 別の物 | 約0.6秒で棚へ戻し、ヒント段階を更新して`question`へ |
| `question` | Space／ヒント | 輪郭や一部の色を表示する |
| `story` | 約4〜6秒／演出後にEnter | お礼の小劇。次の動物か`complete`へ |
| `complete` | 1〜5／動物 | 対応する動物が短いお礼の仕草 |
| `complete` | Enter／べつのおきゃくさん | 新しい5問セットを作り、ヒントを初期化して`question`へ |

数字キーは候補の下にキーの絵として示し、同じ順で画面上段のキーボード図と対応させる。候補が2つなら3は反応させない。長押しのリピートと、渡す演出中の追加入力は無視する。

## 6. 問題・ヒント・間違いの設計

- シルエットは正解画像のアルファマスクから生成し、正解と影の形が厳密に一致するようにする。
- 選択肢は大きさをそろえすぎて特徴を失わないよう調整する。細い物は拡大し、影と選択肢で縦横比を変えない。
- 誤答候補は形が明確に違う物にする。ほぼ同形のスプーン2種、左右だけ違う傘などは使わない。
- 正解の番号は問題ごとにシャッフルし、1〜3のどこにも出るようにする。表示中の候補順は動かさない。
- 1回目の迷いでは影の外周をゆっくりなぞる。2回目では影の一部をカラー表示し、3回目では正解の絵を半透明で重ねる。
- 手動ヒントでも同じ段階を進められる。ヒント使用による完成演出の差は設けない。
- 別の物を選んだら動物が首を少し傾げ、「かたちをみてみよう」。物は壊れず、進捗も減らない。
- 正解後の小劇は毎問異なる。正解マークだけで済ませず、その物を使う意味が見えるようにする。
- 完成画面では点数や誤答回数を出さず、動物と忘れ物の組が並ぶ。お礼を聞くためにもう一度押せる。

## 7. 必要な素材

| 分類 | 素材 |
| --- | --- |
| 店 | 日よけ、カウンター、棚、吹き出し、小劇用の共通背景 |
| 登場人物 | 12動物の来店・待つ・受け取る・お礼。体の角度を共通化 |
| 忘れ物 | 12物のカラー画像、同じ形のマスク、持った時の取り付け位置 |
| 小劇 | 雨、プリン、花、氷の家、絵本、雪だるまなど各話の小物 |
| UI | キー図、候補枠、輪郭ヒント、完成の5組の枠、ホーム |
| 音 | 来店、物を渡す、受け取る、各小劇の効果音、案内、お礼、BGM |

透過WebP/PNGとSVGを使用する。物の画像は影生成用と表示用で別々に描き直さず、同じ原画から出力する。音声で物の名前を言うのは正解後の任意の短い案内とし、解答に必要な情報にしない。

## 8. 技術構成とデータ

React + TypeScript + Vite。候補と影はDOM画像とマスク、輪郭ヒントは事前生成したSVGを重ねる。

- `LostFoundState`: phase、questionOrder、questionIndex、optionOrder、hintLevel、solvedPairs、selectedOptionId。
- `QuestionDefinition`: id、animalId、targetObjectId、allowedDistractorIds、difficulty、storyId。
- 問題セットは開始時に一度決定し、最初の2問の難度・5問の重複なしを保証する。
- 候補生成は正解を1つ必ず含め、IDの重複と輪郭が曖昧な組み合わせを除外する。
- 正解処理は1回だけ実行し、連打で次の問題を飛ばさない。小劇の開始と終了を独立イベントで扱う。
- 完成画面は実際に解いた組から作り、問題セットの未解答分を表示しない。

配置案: `src/games/shadow-lost-found/{ShadowLostFoundGame.tsx,reducer.ts,questions.ts,stories.ts,components/,styles.css}`。素材は`public/assets/shadow-lost-found/`。成績や誤答履歴は保存しない。

## 9. 子供向けUI・中断

候補は最低96px程度を目安にし、絵とクリック領域を大きくする。1366×768で影と全候補が見える。色だけでなく輪郭が十分区別できる物を選ぶ。操作はクリックでも完結し、Tabでもボタンをたどれる。

設定・タブ移動・フォーカス喪失で小劇と音を止め、再開ボタンを待つ。キーの押下状態を消す。ホームへ戻る時は演出を破棄する。素材を開始前に読み込み、失敗時は再試行を案内する。音なしでも問題・ヒント・お礼が理解できる。

## 10. 受け入れ条件

1. 正解の画像と影の輪郭が全12物で一致する。
2. 全問題に唯一の正解が含まれ、候補に重複がない。
3. 5問の重複がなく、最初の2問が簡単な形になる。
4. 正解番号が固定されず、同じ問題の途中では候補順が変わらない。
5. 誤答と手動操作の両方でヒントが段階的に増える。
6. 何回間違っても続けられ、ヒント使用でも同じお礼を見ることができる。
7. 12組の忘れ物に対応する小劇が正しく再生される。
8. キーボードだけ／クリックだけで5問と完成画面を遊べる。
9. 中断・再プレイで前の選択肢や小劇が残らない。
10. 音なし、倍率変更、Chrome・Safari・Edgeの確認状況を記録する。

問題生成、候補の唯一性、ヒント、連打防止をユニットテスト。輪郭と小劇の対応はブラウザで確認する。試遊では「影と候補を見比べているか」「正解後の動きを見たくて次へ進むか」を観察する。

## 11. 実装順序と公開

1. 傘・帽子・ボールの3物で影と候補の位置合わせを作る。
2. 正解・誤答・3段階ヒントを実装する。
3. まず3組の小劇を完成させ、解いた後の楽しさを確認する。
4. 12組、5問セット生成、完成画面を追加する。
5. 本番音、先読み・中断・再プレイを確認する。
6. 試遊で候補の違いと小劇の長さを調整し、ホームに登録する。

GitHub + Cloudflare Pagesを候補とし、`npm run build`の`dist`を配信。プレビュー後mainへ反映し、直接URLも確認する。本書作成では実装・公開を行わない。

## 12. 将来の拡張と守ること

季節の忘れ物、動物の入れ替え、任意の回転シルエットを候補にする。問題を難しくする前に、小劇の種類を増やす。解答速度を競わせず、見て比べる時間を守る。

## 13. 初回30秒の演出と試遊での判断

初回セッションの最初はウサギと傘を使う。影の候補は傘とボールにして、丸い上部だけでなく持ち手まで大きく見せる。次のセッションからは簡単な形の集合から選ぶ。説明は「おなじかたちは どれかな？」の1文にする。

ここでの初回はページを開いて最初の5問セットを指す。その場の再プレイから通常の抽選に切り替え、初回判定のための永続保存は不要とする。

傘を選ぶと、影と実物が一瞬重なって同じ形だと分かり、そのままウサギが持つ。雨が降って傘が開き、しずくが音を鳴らすまでを最初の30秒の中で返す。色のない形を選ぶ作業と、その後の物語が別々に感じられないようにする。

試遊で候補を順番に押す場合は、誤答を叱るより、影と候補の距離、サイズ、輪郭の見やすさを直す。物の名前を聞かれても答えられるよう正解後の短い案内を用意するが、名前を覚えないと進めない問題にはしない。2回目は別のお礼の場面を見たい気持ちを狙う。
