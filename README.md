# ぽっぷ！あそびば / child_games

4歳からPCで遊べる、ポップなゲームのホームと14本のミニゲームです。キーボードでもクリックでも遊べます。ガシャガシャ遊ぶ3本は、時間制限や完成操作のないフリープレイです。

**遊ぶ人のログインは不要です。** ChatGPT・GitHubなどのアカウント作成、サインイン、招待の受け取りを必要としない公開ページにします。ソースコードの公開と、ゲームページの公開は別です。

2026-11-05に実ブラウザで11本を開始から完成まで試遊し、表示・操作を改善しました。ノートPCサイズの操作欄、バンドの楽器、洗車の自動切り替え、恐竜の全身表示と骨の見分けなどを修正し、再試遊しています。音の聞こえ方と4歳児本人の遊びやすさは未確認です。ゲーム別の評価と検証範囲は [QA_REPORT.md](QA_REPORT.md) を参照してください。

2026-11-06に「おもちゃドラム」「にじいろペンキ」「つみきタワー」を追加。文字キー・長押し・同時押しに反応し、ホームの「ガシャガシャ」から選べます。

## すぐに試す

配布物の `PLAYGROUND.html` は、ビルド済みのJavaScript・CSS・イラストを含む単体版です。ダウンロードしてPCのブラウザで開けます。外部フォント、ログイン、画像生成API、サーバーは不要です。

音と音声は最初の「あそぶ」を押した後に有効になります。日本語の音声案内は端末の読み上げ機能を使用するため、利用環境によって声や対応状況が変わります。音なしでも絵の案内で進められます。

## 開発環境

- Node.js 22.13以降
- npm
- React / TypeScript / Vite
- SVGのオリジナルイラスト、Web Audioによる効果音・演奏

```sh
npm install
npm run dev
```

表示されたローカルURLをブラウザで開いてください。通常のWeb配信では `/games/pancake` のようなURL、単体HTML版ではハッシュ形式のURLを使います。

## コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` | TypeScriptの確認と本番ビルド。出力は `dist/` |
| `npm test` | ロジックのユニットテスト |
| `npm run test:components` | DOM上の画面操作シナリオ。実ブラウザ試遊とは別の検証 |
| `npm run test:all` | ロジックと画面操作の両方を実行 |

| `npm run standalone` | ビルドして `PLAYGROUND.html` を生成 |

画面操作テストの結果は `artifacts/component-results.json` に出力します。このテストは音声・AudioContext・時間経過を模擬し、実際の描画や音を確認したことにはなりません。

## 操作と共通ルール

- 現在の画面で使えるキーを、各ボタンのキーキャップで表示します。
- 従来11ゲームは数字・Space・Enterを使います。ガシャガシャ3ゲームは文字・数字・記号・矢印・Space・Enterで遊び、Enterで終了しません。Escapeで一時停止、Tabでボタンへ移動します。Ctrl / Command / Altを含むショートカットはゲーム入力にしません。
- キーの長押しで工程を飛ばしません。洗う・磨く・移動する場面では長押しも使えます。
- 設定表示、フォーカス喪失、タブ移動で進行を停止し、再開ボタンで復帰します。
- 音量、音声案内、動きの設定だけを端末内に保存します。
- アカウント、広告、課金、ランキング、ゲームオーバーはありません。

## Cloudflare Pagesへの公開案

ソースコードは公開リポジトリ [taksai/child_games](https://github.com/taksai/child_games) で管理しています。ゲーム用のWebサイトの配信は未設定です。

`main` は保護されています。全ファイルのコード所有者は `@taksai` で、PR・所有者レビュー・追加変更時の再承認を要求します。最終マージは `taksai` に限定し、直接push・強制push・削除を制限しています。自己作成PRを扱えるよう、`taksai` のみPR経由の明示的な例外操作が可能です。エージェントはユーザーから対象PRの明示的な承認を得るまで、マージ・自動マージ・例外操作を実行しません。公開前の確認範囲は [SECURITY_REVIEW.md](SECURITY_REVIEW.md) を参照してください。

Cloudflare PagesとGitHubを接続し、ビルドコマンドを `npm run build`、公開ディレクトリを `dist` に設定します。`public/_redirects` はゲームURLから直接開くためのSPAフォールバックです。公開後にトップと各ゲームURLの直接アクセス・再読み込みを確認してください。

公開するゲームのURLにはサインインゲートを付けません。プライベートなプレビューURLを本番URLとして案内せず、ログインしていない新しいブラウザ環境で、ホーム表示とゲーム開始を確認します。

## 試遊の優先事項

まずパンケーキ、洗車、バンドを実ブラウザで遊び、表示と操作の分かりやすさを確認します。その後に全ゲームを一巡します。実際のお子さんとの試遊では、説明せずに押し始められるか、同じ操作をしたくなるか、待つ時間が長すぎないかを観察します。難度は点数ではなく、操作の数・待ち時間・ヒントの出し方で調整します。
